# Prompt Lens 后续开发清单

这份清单用于记录 Prompt Lens 后续对标 Gamma 的产品建设方向。对标重点是产品结构、交互逻辑和完成度，不是照搬 Gamma 的视觉皮肤。

## 产品定位

Prompt Lens 可以按 `Gamma for AI media creation` 的方向继续推进。

Gamma 的核心是：输入想法，生成演示、网页、文档。

Prompt Lens 的核心是：输入想法或上传素材，完成视频分析、视频生成、音频分析、视频剪辑，并逐步扩展到 Agent 自动调度这些工具。

保留 Prompt Lens 自己的视觉识别：米黄色暖纸背景、terracotta 陶土橙强调色、浅灰半透明输入框、淡线条地图/流程插画、轻漫画媒体封面图。

## 阶段 1：首页落地页

目标：让新用户 10 秒内理解产品是什么、能做什么、从哪里开始。

开发项：

- [ ] 新建首页落地页，而不是直接把 Dashboard 当首页
- [ ] 第一屏展示 `Prompt Lens` 品牌和一句清晰价值主张
- [ ] 主 CTA：`Start creating`
- [ ] 次 CTA：`View workflow` 或 `Explore features`
- [ ] 第一屏背景使用米黄色、淡线条、地图或创作流程插画风
- [ ] 第一屏底部露出下一段内容，避免空泛满屏 Hero
- [ ] 第二屏展示四个核心功能：视频分析、视频生成、音频分析、视频剪辑
- [ ] 第三屏展示三步工作流：上传/输入、选择参数、获得结果
- [ ] 第四屏展示适用场景：短视频、广告、课程、品牌参考、剪辑脚本
- [ ] 底部再次放置 CTA，引导登录或进入创建页

验收标准：

- [ ] 首页不做传统冗长 SaaS 营销页
- [ ] 第一屏能明确说明产品用途
- [ ] 视觉风格和登录页、Dashboard 保持一致
- [ ] 未登录点击开始进入登录页，登录后进入 Dashboard

## 阶段 2：登录后创建入口页

目标：像 Gamma 一样，用户登录后先看到清晰的创建入口。

已完成基础方向：

- [x] 登录后进入四功能选择页
- [x] 顶部轻导航浮在背景上，不使用整条白色导航栏
- [x] 四个功能卡使用统一插画风格
- [x] 功能卡可点击进入对应功能页

后续优化：

- [ ] 给四个功能卡增加更明确的 hover、active、loading 反馈
- [ ] History 和 Settings 页面也统一成当前视觉体系
- [ ] 移动端检查四卡布局、导航换行和文字溢出
- [ ] 根据用户使用记录决定是否显示最近使用，但不要破坏卡片对齐

验收标准：

- [ ] 用户不需要读说明就知道该点哪个功能
- [ ] 功能入口和功能内页之间的跳转有明确反馈
- [ ] 页面不出现 Gamma 蓝色渐变或照搬式 UI

## 阶段 3：四个统一结构的功能页

目标：所有功能页使用同一套创作工具骨架，只替换参数和结果类型。

统一页面结构：

1. 左上角小巧 `Back` 按钮
2. 中间 `Welcome, {displayName}!`
3. 一句功能相关的陈述句或引导句
4. 居中的浅灰半透明主输入框
5. 输入框内部左下角上传入口
6. 输入框底部参数胶囊
7. 输入框右下角发送按钮
8. 示例提示词胶囊
9. 进度提示
10. 结果区域
11. 最近记录或历史入口

目标：让用户的生成、分析、剪辑结果成为可复用资产。

开发项：

- [ ] History 从列表升级为作品库
- [ ] 支持按类型筛选：分析、生成、音频、剪辑
- [ ] 支持搜索历史结果
- [ ] 支持复制、复用、继续编辑
- [ ] 支持从历史结果一键进入相关功能页

验收标准：

## 阶段 6：Agent Workspace

目标：增加一个专门服务 Prompt Lens 的 Agent，让用户只说目标，由 Agent 自动调用平台工具。

定位：

四个功能页解决“我知道我要做什么”。Agent 解决“我只知道目标，你帮我拆解”。

第一阶段能力：

- [ ] 接收用户自然语言任务
- [ ] 调用视频分析工具
- [ ] 调用视频生成工具
- [ ] 调用音频分析工具
- [ ] 调用视频剪辑工具
- [ ] 支持联网搜索
- [ ] 展示工具调用步骤和状态
- [ ] 每一步产物写入历史记录
- [ ] 高成本生成操作前请求用户确认

Agent 页面结构建议：

- [ ] 顶部或中间保留大输入框
- [ ] 下方展示任务时间线
- [ ] 工具调用结果以卡片形式展示
- [ ] 搜索结果必须带来源链接
- [ ] 最终产物支持复制、下载、继续编辑

示例任务：

```text
帮我分析这个视频，提取适合小红书风格的镜头提示词，再生成 3 个视频版本方案
```

Agent 应拆解为：

1. 分析上传视频
2. 搜索相关趋势或平台风格
3. 生成镜头提示词
4. 生成视频方案
5. 必要时调用视频生成
6. 汇总结果和下一步建议

验收标准：

- [ ] Agent 不是普通聊天窗口，而是平台工具调度层
- [ ] 用户能看见 Agent 正在做什么
- [ ] 每次工具调用可追踪、可复用
- [ ] 联网搜索结果有来源

## 阶段 7：分享与导出

目标：让结果可以离开平台继续使用。

开发项：

- [ ] 分析结果支持复制 Markdown
- [ ] 视频生成结果支持下载
- [ ] 音频转写支持导出 TXT/Markdown
- [ ] 剪辑方案支持导出 JSON 或文档
- [ ] 生成结果支持分享链接
- [ ] 分享页保持品牌风格，但不暴露用户私密素材

## 全局设计约束

- [ ] 不照搬 Gamma 的蓝紫渐变和具体视觉资产
- [ ] 不做厚重白色整条导航栏
- [ ] 不做卡片套卡片
- [ ] 不使用过粗纯黑大标题
- [ ] 不把开发者名字写死到线上页面
- [ ] 输入框默认不要太高，内容多时自然增长
- [ ] 附件预览放在输入框内部，但不要单独做厚重横栏
- [ ] 发送按钮纸飞机指向右上角
- [ ] 页面文本和按钮在移动端不能溢出或重叠

## 推荐验证命令

每次改页面后至少运行：

```bash
pnpm exec tsc --noEmit
```

需要确认生产构建时运行：

```bash
pnpm build
```

如果改了交互或响应式布局，建议再用浏览器检查：

- [ ] 桌面 1920 宽
- [ ] 笔记本 1440 宽
- [ ] 手机宽度
- [ ] 上传文件后
- [ ] 输入长文本后
- [ ] 生成或分析完成后
