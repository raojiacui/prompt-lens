## 2026-11-09 实际账户要求

- 正确入口：Vibe Pay → 我是网页应用 → 通过页面引导接入 → 产品开通 → 补全信息 → 去处理。旧 verify 链接曾显示“按量付费”，本轮已通过产品选择切回正确产品，并核对原正式 APPID。
- 必填网站访问地址：已上线、可访问、正确的网址，不超过 40 个字符。
- 必填网址经营及支付截图：包含首页、商品/服务页、支付页；需显示完整域名，禁止跳转至其他网站，电脑/手机端截图均可。
- 备注：平台说明需要账号密码登录的网站须说明测试访问方式。本轮未提供账号密码、未创建审核账号、未填写或提交表单；若需访问受保护页面，单独确认专用审核访问方式，不共享所有者凭据。
- 页面标注凭证审核周期为 1 个工作日，提交后在同页查进度；这不构成审核通过或恢复额度的保证。批准后的具体额度仍待平台结果。
- 当前旧正式站与 V2 存在界面/支付路径差异，材料必须与实际可访问的正式版本对应，不拿测试站截图冒充正式站。
- 本轮仅新增正式 ALIPAY_SELLER_ID 的实际值并回读验证，待下一次正式部署采用；没有触发部署、付款或提交材料。

## 可用于填写的应用经营说明草稿

以下仅整理已存在的产品事实，负责人需按平台表单核对后使用，不替代主体资料或审核结论。

- 应用名称：Prompt Lens。
- 正式地址：`https://prompt-lens.cc.cd`。
- 产品形态：AI 网页应用，采用支付宝 `alipay.trade.page.pay` 基础收款接口，应用自建订单、权益与退款处理。
- 服务说明：用户上传视频或导入支持的视频链接，获得拆镜分析及提示词，可编辑、AI 改写，并按可用模型进行生成。
- 收费方式：一次性积分套餐，无自动续费；付款经服务端确认后发放套餐权益，功能执行按报价和交付结果结算。
- 当前开放商品：体验包 ¥21.90，200 积分、20 次改写、12 次链接导入。
- 其他商品：创作包 ¥63.90、大容量包 ¥139.00 当前源码均为待开放，前后端都限制购买；不得在材料中宣称已售卖。
- 展示资源：公开 `/samples` 样例及 `/guide` 使用说明。正式站尚未切换至 V2，审核访问正式地址时看到的页面与新版本有差异，提交材料时应明确版本和可访问路径。
- 售后路径：网站客服说明和登录后的 `/billing#refund-request` 工单；提交申请后需客服审核，未使用套餐可按当前流程申请整笔退款，已消耗或有处理中任务的情况由客服核对。不要描述成无条件自动退款。
- 素材说明：V2 有 7 天项目素材保留期及清理机制，不承诺素材永久保存；正式调度及保留期执行仍需发布后验收。

## 依商家页面要求准备的材料

1. 先保存当前产品的补充材料和整改提示原文，确认产品、主体、期限及提交入口。
2. 表单如要求经营主体或授权凭证，由负责人直接在官方平台提交真实资料；不预设个人创作者必须走企业入驻，也不套用线下门店材料。
3. 如要求网站信息或备案，核对正式域名、网站主体和平台所需凭证；当前没有确认任何备案号或主体授权，不填写占位号码，也不宣称已具备。
4. 如要求业务展示，按页面允许的方式准备实际首页、套餐、分析结果、下单/交付及退款入口的截图或演示。保留测试邀请限制，不给审核者共享所有者账号或密钥；需要审核访问方式时单独确认。
5. 如要求用户协议、隐私或独立退款说明，需另行准备可访问页面。当前源码未找到独立用户协议/隐私政策路由，已有客服及退款工单说明；本条为材料差异记录，不代表已确认平台会要求哪些文件。
6. 按实际清单补齐后由负责人审核并提交；保存受理/审核结果和新额度、生效时间。提交成功不等于解限成功，不预设处理时长或最终可收款额度。

## 生效前后的技术顺序

1. 核对商户 UID 后补齐正式 `ALIPAY_SELLER_ID`，使通知接收方校验生效；不修改现有应用私钥、公钥或 APPID。
2. V2 正式部署前完成剩余前置项；当前旧正式站的通知路径尚未部署，不能开展新正式收款链路验收。
3. 正式 V2 上线后验证 `https://prompt-lens.cc.cd/api/payments/webhooks/alipay` 接受 POST、无重定向；校验签名、订单、金额、收款方和 APPID，幂等发放并返回 `success`。
4. 按 Worker 上线记录恢复正式调度前，先确认历史待支付订单和清理记录的处理范围。查单补偿不能代替真实通知验收。
5. 真实付款须另获负责人明确授权，并由负责人亲自确认金额和付款；按当前实际套餐验证到账一次，退款则使用另行明确批准的未使用订单。不改成 1 分钱假套餐，不为探测额度反复发起交易。
6. 商户状态、额度、到账及售后均有证据后再确认正式开售；两个待开放套餐是否开放单独决定，不在本次核查中调整价格或购买开关。
