## Current Product State

The Phase 1 workflow chain is now represented in code:

```text
Reference Video Upload
  -> Project
  -> FFmpeg Worker Breakdown API contract
  -> Scene Blueprint
  -> Editable Scene Prompts
  -> Original Version
  -> Remix Version
  -> Original vs Remix Compare
  -> Send Scene Prompt to existing Generate page
```

The local fallback creates a single-scene blueprint when `FFMPEG_WORKER_URL` is not configured. Real multi-scene detection depends on implementing/deploying the Cloud Run FFmpeg worker with the `/breakdown` contract.
