# ADR 0092：主站发布图片分析商业计费和模型调整

日期：2026-11-28。状态：用户已授权，待完成发布验证。

## 背景和授权

用户明确要求“把图片分析扣除积分还有模型这一部分的代码发布主站”。目标为 `prompt-lens.cc.cd`，Vercel 项目 `prompt-lens`（`prj_LA38e0saqqVw1OkQ95AyoMx5vjIV`），Git 分支 `prompt-lens-V2`。发布前正式域名部署为 `dpl_2wBTAB6vr4YUNQpMKMKKLXmp4z2W`，Git SHA 为 `f29a1d5de3d5968aac7c4618e9c727f1ec8b5786`，来源为 Git。

## 决策

在独立主站 worktree 合并主站最新数据库连接修复，再选择性合入根目录提交 `0988b31`、`34de632`、`6f2897c`。发布图片报价版本 `2026-11-28-image-v3`：DeepSeek V4.1 Flash 默认每张 2 积分，Gemini 3.6 Flash 可选每张 4 积分；移除 3.5、3.7、3.8，后端拒绝调用。确认后预留商业积分，有效结果保存后结算，失败按零结算；不占视频试用，自带 Key 不扣平台图片分析积分。

保留线上数据库关闭预编译语句的修复。冲突文件 `lib/workflow/full-video-script-rewrite.ts` 属于尚未发布的脚本工作台，本次保持主站原有删除状态，不引入该模块。其余模型注册、默认分析、单镜头改写、报价、指南及成本文档按最终方案合入。

先完成本地验证和提交，再推送正式分支，通过现有 Git 集成自动部署。保持根工作区绑定 V2 测试项目，不使用 CLI 上传、不手动提升，不修改环境变量、登录允许名单、存储 CORS 或数据库结构。

## 备选方案

整段发布测试分支会包含用户本次未要求上线的脚本工作台功能，排除。直接 CLI 上传会使 Git 来源和发布审计不一致，排除。直接拷贝文件会覆盖主站差异，采用选择性提交并处理冲突。

## 后果与验证

图片新增明确收费确认，历史记录与报价快照不重算。旧客户端请求撤下型号会被拒绝，沿用现有失败释放和恢复流程；不静默替换旧任务模型。无需迁移和线上余额调整。

验证独立主站版本的全量测试与生产构建；发布后核对远端正式分支 SHA、Git 来源部署 SHA、项目 ID、正式域名部署 ID及 READY 状态。检查公开指南的 2/4 积分价目、默认模型资源、未登录 API 认证保护和近期运行错误。本轮不额外调用真实付费模型；既有本地浏览器和隔离数据库测试证明交互与结算，线上真实付费端到端不据此标为已验收。

发布前验证：独立主站版本全量测试及生产构建通过。该 worktree 未复制生产环境变量，本地构建的认证环境提示不代表生产配置缺失；已只读核对生产认证、商业消费、KIE 和后台调度变量的元数据，未读取密钥值或变更配置。生产运行状态仍须在 Git 部署后检查。
