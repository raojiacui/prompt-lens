# 主站分析模型切换

- 日期：2026-10-31
- 范围：main 主站；V2 保持原提交。

主站此前将页面标注为 Gemini 3.8 Flash 的选项映射到 DeepSeek。现将界面收敛为 DeepSeek V4 Flash（默认）与 Gemini 3.8 Flash 两个真实选项，费用来源单独选择平台试用或自有 KIE Key。DeepSeek 实际 ID 为 `deepseek-v4-1-flash`，继续走 Responses 图片协议；Gemini 实际 ID 为 `gemini-3-8-flash`，恢复其原先明确配置的 OpenAI 兼容频道。旧版 3.5、Pro 的服务端 ID 保留兼容，平台额度与自有 Key 权限仍由服务端校验。

模型与费用来源在请求执行中锁定。失败后用户可手动更换模型重新提交；不自动跨模型提交，不增加重试次数。KIE 503/504/524、服务端错误、限流及超时的最终失败提示上游网关繁忙、未获得结果，并建议切换模型；输入文件 404、Key 错误与其他本地异常保留原原因。这不是对所有 524 根因的判定。两个模型都经过 KIE，因此切换不能保证避开整个供应商的故障。

验证覆盖模型 ID、费用来源边界、图片请求协议、模拟上游响应与错误提示；不主动消耗付费额度做在线推理。
