# ADR 0090：分析与结果交付修复同步主站

## 背景与授权

2026-11-28 用户确认测试成功，并明确要求“把这一部分的代码同步到主站”。正式域名 prompt-lens.cc.cd 的发布前部署为 `dpl_4CPFgnxzPqXtYUBzF1JWB46ye1Bn`，Git SHA 为 `436f21943958fafbb7f0e16f4f5809184c0d78ba`。测试分支还有其他未上线功能，不能整体替换正式版本。

## 决策

从主站基线建立 codex/analysis-image-hotfix，只选入本轮图片及关键帧内联传递、KIE字段协议、无效视觉结果拦截、多JSON恢复、明确付款来源、结果检查点与共用视频保存恢复策略，以及已授权的退款流水说明展示。只解决审计文档的摘取冲突，不引入其他新功能、定价、数据库迁移或环境变量调整。

关键分析、保存、计费展示源码已与用户验证成功的测试分支逐文件比对一致；分析页面只带入图片付款来源修复，不带入完整脚本工作台等其他测试功能。通过 Git 推送正式分支 prompt-lens-V2，交由主站项目的 Git 集成发布，禁止 CLI 上传或手动提升。

发布工作区单独绑定 prompt-lens / prj_LA38e0saqqVw1OkQ95AyoMx5vjIV，原工作区保持 prompt-lens-v2-test 绑定。测试项目只构建 staging/v2，不改变其分支限制。

## 备选与后果

整体合并测试分支会超出本次授权范围；手工上传会绕开可核对的 Git 来源，均不采用。最小补丁需要独立回归和生产构建，但可以保持发布来源清晰。历史失败任务没有凭空恢复，已退还的6积分不重复执行；主站发布不产生额外模型调用。

## 验证与回退计划

在独立候选上完成完整本地回归与生产构建，再提交和推送；核对远端SHA、正式项目ID/名称、Git分支和部署SHA、正式域名与READY状态。以无登录状态检查登录跳转和敏感接口鉴权，不自动发起付费模型测试。主站若出现回归，优先保留证据并通过Git回退本补丁；发布前的正式SHA作为回退基线。在线完整登录、实际模型耗时与端到端交付按各自证据判断，不将READY当作全部验收完成。
