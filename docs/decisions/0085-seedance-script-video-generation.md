# 0085 从完整脚本预览并生成 Seedance 2.5 长视频

## 背景

负责人要求打通完整脚本、提示词预览、Seedance 2.5 生成 30 秒视频的流程。完整脚本文稿已有独立修订，现有任务、历史和输出审核可复用。

## 决策

- 在既有模型注册表加入 KIE `bytedance/seedance-2-5`，首版开放纯文本、4–30 秒、480p/720p/1080p，标记实验性且仅自带 Key。平台积分模型列表和后端报价均排除此模型，其他已发布模型及付费能力保持原有行为。暂不开放参考素材、自动时长、4K、延长与动作迁移。
- 编译器根据结构化脚本、角色、全局风格、原始镜头时间点和目标参数生成提示词，不调用 AI，不收取改写额度。允许用户编辑实际提示词后重新预览；单次提示词限制 20,480 字符，超长不截断；原始镜头超出目标时长时要求调整脚本或选择逐镜生成。
- 当前强制 Waffo 提示词审核上限为 10,000 字符，因此 10,001–20,480 字符的完整编译稿可预览、复制和手动精简，生成确认保持不可用，直到用户精简并重新预览。服务端在调用供应商前同样拒绝超出审核上限的快照；不拆段绕过整篇语义审核，不放宽审核门禁，也不改动原脚本。
- 预览返回十分钟有效的服务端签名快照，包含用户、项目版本、脚本修订 ID、源文稿哈希、实际提示词、时间点、模型和参数。预览不创建生成任务；确认后将快照持久化到现有 `workflow_jobs.input`，不写回原分镜。
- 以签名快照中的 UUID 建立唯一任务，使用数据库锁和状态比较保证同一预览只提交一次；网络未知状态不自动重发。供应商返回任务 ID 后先持久化，再关联 `video_generation`；刷新或历史查询可恢复已知任务。没有供应商任务 ID 的未知请求明确要求核对 KIE 控制台，不假装失败退款，也不自动再次付费提交。
- 只读取该用户的 KIE Key，不回退平台 Key 或其他供应商。确认界面展示时长、分辨率、声音、一次生成数量及 KIE 账户承担费用；不伪造未核实的平台积分报价。调用前复用提示词审核，输出复用现有状态查询与交付审核，未通过审核不展示视频地址。
- 生成记录保留项目版本和脚本修订关联，后续脚本编辑不影响已提交任务；文稿和冻结提示词随现有七天内容保留策略清理。

## 备选方案

直接把脚本拼接到普通生成页无法可靠冻结修订，也缺乏提交幂等。单独建立长视频模型列表会与现有能力配置分叉。新建生成表和全量重构 Composer 会扩大本轮迁移范围，因此复用已有任务及历史结构。

## 后果

BYOK 用户可以先使用明确参数体验长视频。真实供应商成功生成、实际成片时长和多镜头效果仍需独立收集证据；本地 mock 成功及部署就绪均不能代替这项验收。长视频不保证精准按秒切镜。

## 验证计划
