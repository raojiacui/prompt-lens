# ADR 0025：有效会话的 API 缓存续验与同任务安全恢复

- 日期：2026-11-06
- 状态：已采纳，本地认证与浏览器回归通过；发布后需原浏览器复测。
- 关联：ADR 0008、ADR 0024

## 背景与证据

用户确认分析任务 `b2c5ab7b-bd78-470f-ac31-51b4efe4621d` 后，页面很快显示“登录校验失败”，进度停留 0/8。测试库初查任务实际在运行，已有两个镜头完成、两个分析中，其余排队。账号有有效的数据库会话，数据库最早有效会话的到期日在 2026-11-26；排查未读取或记录用户会话 Token。

代码审查发现：受邀测试白名单中间件只用 Better Auth 的十分钟 Cookie 缓存判断 API 访问。缓存缺失或过期，即使存在仍有效的会话 Token，也直接返回 401。页面导航已有服务器端会话续验重定向，API 轮询没有对应恢复能力，因此页面可显示认证失败，而已确认的后台任务继续执行。真实 Better Auth 内存会话测试复现了这一分支；没有直接采集原浏览器 Cookie，因此不能仅凭此测试断言原请求的所有 Cookie 状态。

排查期间原任务已正常完成：8/8 镜头、8 条有效 KIE 分析结果，结算 19 积分。钱包可用积分 912、预留 0；本轮没有重新确认任务或补提模型请求。

## 决策

- 保留中间件白名单拦截。仅在缓存无法识别账号但存在会话 Token 时，给原 401 增加 ACCESS_SESSION_REFRESH_REQUIRED 标记。原业务路由此时没有执行；匿名或已识别为非白名单账号的请求不获得该标记。
- 在既有 `/api/session-refresh` 增加同源 POST 续验接口。必须校验 Origin，通过 `disableCookieCache=true` 查询真实数据库会话，重新检查受邀邮箱白名单；成功才转发 Better Auth 签发的 Cookie。保持既有会话期限、Cookie 配置和 GET 页面导航流程，不开放匿名权限、不创建替代登录会话、不改变登录提供商。
- 真实无效、撤销、伪造或非白名单会话返回 401；跨来源请求返回 403；数据库暂时不可用返回 503，不把认证基础设施故障误报为明确退出登录。不记录 Cookie、Token 或密钥。
- 视频工作区、分析弹窗和独立任务页通过共享请求函数处理该明确标记：并发请求复用一次续验，成功后最多重试一次原 URL、原任务 ID、原请求正文。不因续验创建新报价或新任务。
- 普通 401、403、5xx、网络中断或未经确认的付费响应不能触发自动重放。只有中间件标记的拒绝能证明业务逻辑尚未执行。外部地址和不可重放的请求体不执行恢复；原请求取消后不重放。续验失败保留真实状态，停止该次自动恢复。
- 继续由正常业务路由验证登录、归属、报价、预留与结算。服务商未知结果不重复提交，后台正在运行的原任务不受续验影响。
- 只推送 V2 分支，由测试项目 Git 自动构建；发布前确认所有活动任务结束，发布后核对固定测试域名与正式站部署 ID。

## 备选方案

- 延长 Cookie 缓存或取消到期检查：增加权限变更陈旧窗口，仍不能解决缓存丢失，不采用。
- 中间件只要看到 Token 就直接放行：Token 尚未通过服务器验证，而且可能绕过受邀白名单，不采用。
- 所有 401 都重新登录或重放请求：会中断正在运行的页面，且可能重复不确定的付费请求，不采用。
- 自动创建新任务恢复显示：会重复模型调用和费用，不采用。

## 后果

有效会话在测试站缓存到期后会有一次短暂数据库续验和一次原请求重试，用户可继续查看同一任务。真正失效的会话仍需要重新登录。Cookie 被浏览器拒绝时，该次最多恢复一次，不无限循环；网络中断时保留已确认任务，不能据此认为后台停止。其他尚未接入共享请求函数的页面继续使用既有导航续验，不将本次改动宣称为所有页面的统一认证重构。

## 验证

- 78 项单元与集成回归通过，包含真实 Better Auth 会话的 HTTP/HTTPS 缓存恢复、撤销/伪造/非白名单拒绝、同源检查、原 Cookie 名兼容、管理端封锁和任务归属检查。
- 共享请求函数验证并发续验、同任务/同正文、单次重放上限、匿名普通 401 不重放、5xx/网络异常不重放、续验 401/503 不继续提交、外部地址与不可重放正文排除、取消请求不重放。
- 五项本地浏览器回归通过，包括两个新增用例：真实浏览器接受续验 Set-Cookie 后读出同任务结果；数据库会话无效时仍显示认证错误。均断言付费确认只有一次，未重新准备或创建任务。另三项既有预览与报价恢复继续通过。
- 修正旧 HMAC 篡改测试：修改 Base64URL 末尾符号可能只改变未使用填充位，无法保证解码字节变化。改为修改首符号并断言实际 HMAC 字节不同，继续验证签名拒绝，没有放宽认证。
- TypeScript、差异格式和 Next.js 生产构建通过。测试夹具不代表已在原用户浏览器完成上线后的 Cookie 续验，真实浏览器复测仍未验收；本轮不读取用户 Token 来冒充该验收。
