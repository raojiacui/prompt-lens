# ADR 0017：分析任务的后台阶段与状态同步可见性

- 日期：2026-11-03
- 状态：本地验证完成，待 V2 测试站发布与用户任务核验

## 背景

用户反馈十镜头分析等待近六分钟，页面始终显示“正在准备镜头素材”。现有状态接口只返回准备、分析、保存三个大阶段，缺少逐镜头运行与耗时。查询失败后仍保留处理文案和估算进度，用户无法区分后台耗时与状态查询中断。线上请求记录还显示认证缓存到期后持续返回 401。

本次只读诊断发现，任务 `27259858-b24c-4696-8bd8-cd096b678468` 的请求日志有调度唤醒成功记录，但目标数据库内仍为 quoted，且没有对应镜头任务和积分预留。该差异尚未定位，不能据此宣称模型慢、任务正在执行或分析已验收。

## 决策

- 在现有分析面板增加可展开的“后台任务详情”，并在 `/billing/tasks/[id]` 独立页面默认展开。显示服务器阶段、任务 ID、模型、最近同步时间、最近后台检查点、各镜头状态和排队/素材/模型/保存耗时。
- 通过任务接口的 `diagnostics=1` 参数返回诊断投影，仅在确认登录及任务所有权后读取镜头记录。使用明确字段列表，禁止返回原始输入、素材 URL、签名 URL、Key 指纹、模型回答和错误堆栈。
- 为新执行的镜头记录准备、等待模型、保存阶段及时间；保留任务领取、并发上限、购买校验、预留与结算规则。读取详情不新增付费任务，不主动重提推理。
- 在确认成功与执行领取处记录脱敏日志，便于关联同一任务的生命周期。
- 查询遇到 401 或网络失败时，显示上次快照和同步中断，暂停进度估算，提供独立任务页入口。401 后降低查询频率，用户可在独立页面恢复登录；不放宽邮箱邀请名单或认证边界。
- 将后台检查点与浏览器同步时间分别显示。超过两分钟无检查点只提示待检查，不能推断进程仍在运行或已经失败。历史任务缺少耗时显示“—”，不回填估算数据。

## 备选方案

- 向用户显示完整服务器日志：含有密钥、素材或供应商内容的风险，也缺少任务所有权边界，不采用。
- 拉长预计时间或平滑进度条：无法区分慢请求、未调度与登录失效，不采用。
- 增加独立监控服务和数据表：已有任务和镜头检查点足以承载第一版诊断，暂不增加基础设施。

## 后果

开启诊断的轮询增加一次按任务 ID 索引读取的镜头查询；新镜头增加至多两次阶段写入。阶段写入遵循执行 ID 校验。诊断展示不消耗模型额度。历史记录无法还原未采集的阶段时间。

## 验证计划

- 测试任务和镜头投影、敏感字段排除、重试镜头编号和阶段识别。
- 验证接口的登录与所有权限制，以及未请求诊断时无需额外查询。
- 检查桌面与手机详情展示、查询断开和 401 提示。
- 运行相关任务、数据库模拟回归、类型检查与生产构建。模拟测试不代表真实模型或支付验收。
- 仅部署 V2 测试项目；部署前核对项目绑定与活动任务，部署后核对主站部署 ID。

## 本地验证结果

- 诊断与界面 32 项测试通过；商业钱包/逐镜头执行回归 122 项通过、1 项既有用例跳过。测试数据库为本地 PGlite，模型与支付均为模拟。
- TypeScript 检查、生产构建通过；构建保留已有 OAuth 配置、Edge 依赖和 lint 警告。
- 在独立 localhost:3007 的生产构建上，用隔离测试密钥、两个受邀邮箱名单和模拟 API 验证 1440/390 宽度：逐镜头状态、阶段耗时、横向滚动、查询失败时保留上次快照及同步恢复均通过（2 项浏览器用例）。没有关闭测试站的登录或产品功能。
- 本地开发分支与线上 V2 分支已分叉，本次在基于线上提交 `4493ff4` 的独立工作区与 `codex/v2-task-monitor` 分支完成，保留原工作目录及其未提交文件。
- 线上模型耗时与任务记录差异仍需用户登录后的状态快照或下一次真实执行日志核验；这些本地检查不构成完整分析端到端验收。
