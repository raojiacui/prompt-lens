# ADR 0087：图片分析保留明确的付款与密钥来源

## 背景

2026-11-27 管理员报告选择平台积分后图片分析仍调用 Infistar。生产任务为 mode=admin、keySource=user、provider=infistar。前端选择图片后隐藏付款来源，直接分析提交没有 payer；后端的管理员权限与个人凭据优先逻辑最终选中个人 Key。该次调用超时且站内未收费，不能视作平台 KIE 故障。

## 决策

- 管理员上传图片后继续显示费用来源，将选择传入直接分析请求。管理员显式选择平台时固定平台 KIE；显式选择自带 Key 时仅使用该用户自己的首选供应商凭据，缺失则拒绝，不回退。
- 旧客户端管理员直接分析没有 payer 时默认平台 KIE，避免再次静默使用个人凭据；新任务持久化 provider、keySource 和密钥指纹，执行保持绑定。
- 普通账号选择平台消耗必须进入现有商业报价确认流程；直接请求不得偷偷改用个人 Key 或获得管理员权限。本次不新增普通用户的付费图片套餐或更改既有图片试用行为。管理员直接分析沿用原有免站内扣费权限。
- 不重提历史超时任务，不切换既有任务的 key，不重复消耗供应商额度。

## 备选方案

仅调整文案无法约束后端密钥；全局修改个人 Key 优先级会影响其他功能；新增图片商业定价超出此次修复范围。选择在直接分析入口显式处理付款来源。

## 后果

管理员可以明确选择费用承担方，前端和执行记录一致。普通账号图片继续沿用原有入口权限，不能通过伪造 payer 获得免费平台消费。

## 验证计划

独立数据库测试管理员平台与自带 Key、Infistar 首选、旧客户端默认值，以及普通账号伪造平台参数的拒绝。浏览器验证上传图片后选择仍显示且提交携带 payer，回归视频商业报价和试用流程。按项目 Git 发布规则验证，生产发布须单独授权。
