# 0014：将核心视频拆解流程打包为纯本地 Agent Skill

- 日期：2026-10-28
- 状态：已采用，首版技能包进入本地验证。

## 背景

Prompt Lens 已沉淀自动拆镜、代表帧采样、逐镜头画面分析、复刻提示词、剧本改写和做同款的完整方法。用户希望将这套方法作为可销售的 Agent Skill，使购买者能够在自己的本地 Agent 中处理视频，并优先使用 Agent 自带模型额度或自行配置的服务商 API。

Agensi 可以分发 `SKILL.md`、参考资料和文本脚本，并在买家 Agent 会话的临时目录执行脚本；平台不会为创作者托管 FFmpeg、Python 依赖或自建 MCP 服务。把现有 Web 应用、数据库、R2、媒体 Worker 和平台模型密钥一起复制到技能包，会显著增加安装、运维、隐私和成本边界，也偏离用户要求的本地流程产品。

## 决策

- 在仓库的 `skills/prompt-lens-video-remix/` 维护独立技能包，不调用 Prompt Lens 后端，不依赖 Prompt Lens 账号、R2、数据库或平台 Kie.ai 密钥。
- 本地准备阶段只依赖 Python 3.9+、FFmpeg 和 ffprobe。技能提供只读环境检查脚本，以及确定性的拆镜和三帧采样脚本；不打包二进制文件或第三方 Python 包。
- 视觉理解优先使用当前 Agent 的原生多模态能力和用户已有额度。能力不足时，由用户自行选择服务商并通过 Agent 密钥存储或标准环境变量配置 API；技能不收集、保存或传输密钥。
- `yt-dlp`、语音转写和视频生成属于可选增强能力。缺少依赖时先解释用途，安装、联网下载、媒体上传、付费 API 调用和视频生成都要在执行前取得用户同意。
- 本地脚本只接受本地文件，写入新的或空的输出目录，不覆盖和删除已有文件。链接输入先由 Agent 在用户授权后下载为本地文件，再进入同一处理流程。
- 事实分析与创作改写分开保存。逐镜分析使用统一证据和置信度规则；改写或做同款在用户选择后执行，保留原始分析供比较。

## 备选方案

### 连接 Prompt Lens 云端 API

可以复用现有媒体 Worker、存储和模型服务，跨 Agent 的输出一致性更高。该方案需要新增 Agent 鉴权、媒体上传、计费、隐私政策和长期服务承诺，也会让技能依赖我们的线上可用性，因此不作为本地技能首版。

### 在技能包中复制完整处理栈

完整处理栈包含二进制工具、服务端依赖和持久化基础设施，超出 Agensi 的文本技能交付边界，也会增加不同操作系统上的失败率，因此不采用。

### 只提供提示词说明，不提供脚本

交付最轻，但每个 Agent 会自行重写拆镜和抽帧逻辑，结果难以复现，用户价值也低。首版保留安全、可审计的确定性脚本。

## 后果与权衡

- 用户视频默认留在本地，技能没有我们的持续推理和存储成本，适合一次性销售或低维护订阅。
- 处理质量会受本地 FFmpeg 可用性和 Agent 多模态能力影响；技能必须清楚报告缺失能力，不能承诺所有 Agent、链接和视频格式都能运行。
- 三帧采样能稳定描述主体、构图和主要变化，但可能遗漏采样点之间的瞬时动作；输出必须标记运动、音频和身份等不确定信息。
- 社交平台链接的可用性取决于用户环境中的下载工具和平台规则。首版不宣传“任意链接均可解析”。
- 后续如需要稳定的跨 Agent 工具协议，可另行评估远程 MCP 或云端增强版；该变化需要新的 ADR，并保留本地模式。

## 验证计划

- 使用技能规范校验器检查名称、frontmatter、引用路径和未清理模板。
- 在 Windows 本地环境运行环境检查脚本，确认不产生文件和网络副作用。
- 使用仓库内测试视频运行拆镜脚本，核对 `manifest.json`、`storyboard.md`、场景连续性、单段时长和每镜头三张代表帧。
- 验证输出目录非空时明确失败，避免覆盖已有结果。
- 生成 Agensi 上传 ZIP，确认只包含技能所需文本和脚本，不包含测试输出、缓存、媒体或密钥。

## 已完成验证

- `quick_validate.py` 通过，`SKILL.md` 的名称、frontmatter 和模板清理符合技能规范；`agents/openai.yaml` 可由 YAML 解析器读取，默认提示正确引用技能名。
- 环境检查脚本在 Windows 上识别 Python 3.13、FFmpeg、ffprobe 和可选的 yt-dlp，退出码为成功；脚本没有安装、联网或文件写入行为。
- 使用仓库内 59.234 秒的 `demo.mp4` 完成真实烟测，输出 8 个连续场景、24 张代表帧、`manifest.json` 和 `storyboard.md`。首段从 0 秒开始、末段覆盖到视频结尾，最长场景 9.733 秒。
- 使用三段纯色视频验证已知切点，脚本在 1.0 秒和 2.0 秒检测到切换，得到三个各 1 秒的连续场景。
- 对同一个非空输出目录重复执行时明确拒绝；将现有文件作为输出路径时明确拒绝，没有覆盖已有文件。
- 已生成 12,647 字节的 Agensi 上传 ZIP；归档只包含一个顶层技能目录及其中七个必需文本和脚本文件，没有测试媒体、抽帧、缓存、密钥或项目运行文件。
