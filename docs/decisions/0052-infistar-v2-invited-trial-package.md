# ADR 0052：为 Infistar 受邀邮箱开通 V2 体验包测试权益

- 日期：2026-11-10
- 状态：已接受；数据库、应用权益计算及本地访问策略已核验，白名单部署待验证。
- 关联：ADR 0002、0005、0023。

## 背景

项目负责人明确要求为 `outreach@infistar.cc` 开通 V2 测试订阅，功能权限与 ¥21.90 体验包一致。该邮箱尚未在测试库注册，原邀请名单只有两个内部测试邮箱；此次授权将其扩展为三个邮箱。工作区存在无关的未提交改动，远端 V2 分支也领先当前工作区，因此使用基于远端已部署提交的隔离工作区处理本次记录和部署。

## 决策

- 只操作 Supabase `prompt-lens-v2-test`（`mwczjgflbmzgvebfilnf`）和 Vercel `prompt-lens-v2-test`（`prj_wGvOLlXsOzpVUGZiK3spsAIxXAjI`）。
- 预置普通用户 `27529852-8064-47d0-8719-c90b024a5605`，邮箱保持未验证；首次登录由本人接收并提交邮箱验证码。不授予管理员角色，不创建密码或会话。
- 按 `v6_trial_200` 一次性发放 **200 积分、20 次改写、12 次视频链接导入**。正常开放功能沿用与体验包相同的入口、模型选择和计费流程；不绕过额度预留、扣减、释放或服务商密钥要求。
- 发放事务锁定邮箱和钱包，核对钱包与 active 批次一致，同时创建批次和账本；事件键 `test-grant:v2:2026-11-10:outreach@infistar.cc:v6_trial_200` 用于防止重复发放。
- 链接导入沿用既有测试权益识别格式，以独立的 0 积分/0 改写账本事件关联批次 `7c3c39a6-4814-4a8b-86d8-3ff0b562d408` 和测试引用 `81e876fd-ed22-4d92-af9d-3d99814617fd`；元数据明确包含测试来源、测试环境和 `noRealPayment=true`。
- 三个 Vercel 环境和本地 `ACCESS_ALLOWED_EMAILS` 同步为 `raojiacui@gmail.com,raojinbo@gmail.com,outreach@infistar.cc`，保留邀请限制，继续拒绝历史拼错邮箱。
- 本次没有真实付款，不创建付款订单、购买流水或自动续费订阅。套餐是按量权益，沿用现有有效期规则。
- 本地验证并提交后，仅推送 GitHub `prompt-lens-V2` 分支，由其 Git 集成自动部署白名单变更。正式站保持当前部署 `dpl_AhKmkGrgiKoL25A8KfS8jcLGcBAV`。

## 备选方案

- 等待收件人注册后再发放：需要再次运维，无法立即预备完整测试账号。
- 赋予管理员或关闭白名单：扩大授权范围，无法代表普通体验包行为。
- 伪造支付订单或仅修改钱包余额：污染交易语义或破坏批次预留一致性。

## 影响

收件人可以使用与体验包相同的已开放功能，实际执行正常消耗测试权益。积分可用于付费分析、拆镜和已核价的生成任务；改写和链接导入分别消耗次数。此授权不表示无限额度，也不保证服务商、密钥和后台 Worker 的每次调用都成功。

预置用户未触发应用注册欢迎邮件；未向收件人发送通知或验证码，登录由本人操作。正式项目、其他用户的余额和支付数据保持不变。

- 上线后核对三个环境的精确邮箱名单、远端分支 SHA、Git 来源部署 SHA、固定测试域名和正式站部署 ID。
- 真实邮箱验证码登录、模型分析、改写、链接导入及生成的逐项端到端验收仍需收件人操作；未将这些项目标记为通过。
