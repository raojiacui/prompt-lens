# ADR 0024：预览不可用时复用原素材恢复，区分读取中断与素材过期

- 日期：2026-11-06
- 状态：已采纳，本地验证完成；发布后仍需原页面复测。
- 关联：ADR 0023、ADR 0017

## 背景与证据

用户在 V2 测试站导入抖音视频后看到“拆镜预览已超出素材保留期或不可用，请返回后重新上传素材”。日志确认导入已成功保存，源文件 2,488,755 字节、26.75 秒，公开 HEAD 可读。导入请求 `d639a755-f7ff-4a84-8d71-b93ec4f679a9` 已按成功结算，只消耗一次导入权益；账号仍为 931 积分、19 次改写、无预留。

初次排查时，项目 `da42d280-4d6a-48d6-a7bd-0f1366fb9bb0` 尚无已持久化的拆镜预览。复用该用户的入库记录和源视频，通过真实 V2 预览函数成功生成八个镜头，预览 ID 为 `22a0e281-5165-4b2b-bf91-1b47ed41c965`，有效期至 2026-11-13。未重复调用 EasyDown、未调用模型、未创建付费分析预留。

当前代码在预览不可用时将所有情形显示为素材可能过期。报价失败路径保持原预览，但按钮只重新报价，无法恢复失效的预览 ID。读取完成但任务写回条件失效时也抛出 PREVIEW_EXPIRED，混淆执行中断与七天素材保留期。旧接口未记录这类已知错误的请求阶段，因此现有记录不足以还原用户首次 PREVIEW_EXPIRED 的确切触发原因。此次修复不把该未知原因归结为登录失效。

## 决策

- 前端遇到 PREVIEW_EXPIRED 或 PREVIEW_PREPARATION_INTERRUPTED，明确提示复用当前素材重新读取，无需重新解析链接或上传。报价阶段出现该错误时，按钮切换为“重新读取视频”，清除旧预览请求并以原项目、原媒体地址调用已有准备接口。
- 恢复必须由用户主动点击，不自动确认分析或提交模型任务。重新读取继续经过原登录、素材归属、项目状态、商业权益、限流与预览缓存检查。缓存有效时复用后台已有镜头，不重新调用 Worker。
- 预览重读后按原镜头起止时间恢复选择，不依赖可能变化的镜头 ID。边界不再匹配的镜头不默认加入原选择，仍需用户审核新报价。普通报价刷新保留已有镜头和选择。
- 读取任务的写回条件失效改用 PREVIEW_PREPARATION_INTERRUPTED，与真实保留期或无效预览分开。接口返回 409；旧 PREVIEW_EXPIRED 仍兼容。两个错误都记录安全请求 ID、动作和相关 UUID，保留脱敏异常链，不记录媒体地址或密钥。
- 保留七天媒体保留期和过期清理；本次不延长素材寿命，不取消登录、付款或所有权校验，也不补扣或退还已成功交付的导入次数。
- 按本地验证、聚焦提交、推送 GitHub V2、Git 自动部署顺序发布，仅更新测试项目。

## 备选方案

- 要求重新解析链接或上传：已有入库视频有效，会增加重复导入和用户操作，不采用。
- 对 PREVIEW_EXPIRED 一律取消校验：可能泄露其他账号预览或引用已清理内容，不采用。
- 自动重提分析：尚未取得有效报价及用户确认，可能产生额外模型费用，不采用。
- 仅替换错误文案：无法解决失效预览 ID 被持续用于报价的恢复缺口，不采用。

## 后果

未确认的读取或报价可以在当前素材上恢复，用户需要重新确认有效报价后才开始分析。预览失效但源视频仍有效时可能重新进行一次不收费的 Worker 预处理；原素材真的被清理或不属于当前账号时仍不能恢复。首次错误的确切原因尚未还原，新增请求日志用于后续复测定位，不能以恢复成功宣称所有历史原因都已解决。

## 验证

- 本地浏览器三项回归通过：等待/普通报价失败保留镜头、读取阶段预览错误后原素材恢复、报价阶段失效后重读且按时间边界保留选择。测试断言不调用链接解析接口、不确认付费任务，并覆盖重读后的镜头 ID 变化。
- 钱包与准备路由 144 项回归通过、1 项既有原生 PostgreSQL 专用测试跳过。验证读取执行权失效后分类为中断且原素材可再次准备、未调用模型或生成付费预留；保留未登录 401、账号归属与保留期检查。
- TypeScript 检查和生产构建通过。发布结果在推送后核对；用户真实浏览器中报价与后续付费分析验收尚未完成，保持未通过。
- 正式站发布前部署基线为 `dpl_AhKmkGrgiKoL25A8KfS8jcLGcBAV`；仅在活动任务为空时推送，并在发布后核对固定 V2 域名与 Git SHA、正式站部署不变。
