# ADR 0071：支持删除误添加的违禁词并保留审计

- 日期：2026-11-18
- 状态：本地验证与测试站 Git 发布完成；管理员线上点击验收待执行。
- 关联：ADR 0069、0070。

## 背景

负责人测试动态词库时发现只能编辑和停用，要求添加删除按钮，以移除误添加规则。

## 决策

- 在词库每行编辑旁增加删除按钮，确认时明确该词停止参与拦截、历史审核记录保留。请求期间禁用行操作，成功后刷新词库与记录；删除正在编辑的规则时清空编辑器。
- 复用管理员 POST 接口，新增 delete_term 操作；保留管理员、测试项目、同源校验并验证 UUID。规则已不存在时返回 404。
- 在单个数据库事务中删除规则，并插入 policy_change/deleted 审计，记录管理员、规则 ID、分类和删除时的短语、处理方式、启用状态、修订及备注。审计写入失败则回滚删除；此前审核记录全部保留。
- 现有审核记录 rule_id 无外键约束，允许保留已删除规则 ID；删除快照保留必要上下文。删除后相同短语可重新添加，新规则具有独立 ID。不需要修改数据库结构。
- 请求失败保留表单输入，避免丢失编辑或复核内容。

## 备选方案

- 仅停用：无法移除误添加的词，未满足用户要求。
- 新增软删除字段及部分唯一索引：增加数据库迁移与所有查询的过滤成本；本次采用删除规则、永久保留相关审计记录的方案。
- 连同历史审核记录一起删除：会破坏追溯，不采用。

## 影响

删除影响此后读取词库的新请求，已开始或已完成审核的任务保持原判定。历史记录中的规则 ID 可以不再对应当前词库行，删除审计提供当时规则快照。数据库管理员仍可直接变更数据。

## 验证计划

- 隔离 PGlite 测试真实事务：删除后不匹配、历史保留、可重新添加、审计失败回滚、权限及同源校验、正式项目禁止操作。
- 运行审核相关回归、TypeScript、修改源码 ESLint 和生产构建。
- 按前述测试站发布授权通过 staging/v2 Git 集成发布，核对远端与部署 SHA、测试域名和正式站部署 ID。
- 不操作线上词库测试数据，不调用真实模型。
