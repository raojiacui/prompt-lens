# ADR 0062：依据最新 V2 刷新发布候选、备份与回退基线

- 日期：2026-11-13
- 状态：代码回归、备份恢复、回退归档及候选 Git 部署已验证。正式数据库/Worker 存在两项配套差异，未执行正式更新或 Web 发布。
- 关联：ADR 0031、0032、0037、0043、0050、0051、0053、0058、0060；上线记录第 021 项。

## 背景

负责人说明最近又修改了 V2、目前功能测试正常，并要求开始上线前最后准备。此前基线为 11 月 9 日，之后增加 Infistar、Key 自动校验、拆镜精修、DeepSeek 免费试用和统一历史记录。正式 main 也从 75eb611 更新到 0ae4531，必须刷新候选和回退对应关系。

## 决策

- 按当前远端与部署证据固定候选，不合并 main，不提前切换默认/正式分支，不发布正式 V2。具体来源、更新方案及顺序见 [最终核对单](../v2-release-candidate-2026-11-13.md)。
- 正式业务库重新做一致快照手动备份，仍保持 Free；备份加私有 ACL、本机恢复逐表对比，再仅在恢复副本演练 0025。正式数据及 Key 不修改，备份不公开。
- 回退档刷新为当前正式 main / 0ae4531d18320ee529e4736cb9a41f0b0e94bd4c，固定部署 dpl_BKjZ5RUGiHomYsV4kBbVXW8gTK4P；保留原 11 月 8 日归档，不移动旧标签。
- 正式库缺少测试已应用的 0025；正式 Worker 镜像尚未包含已验收的拆镜精修。两项是实际发布依赖，不能用最新测试站正常替代正式配套验证。先完成可审阅的备份/方案，再确认正式执行范围。
- 修正完整测试中遗留的历史路由夹具，保留真实联合 SQL 的账号隔离检查；只改测试，不改产品行为。此小模块已单独本地提交。
- 日志调度延迟按负责人决定移至上线后，不为最后准备新建监控平台或费用；其他待验证项继续如实记录，不能改验收标记掩盖。

## 备选方案与后果

- 沿用 11 月 9 日的代码、备份和 Worker 结论：遗漏新增结构、算法及当前正式提交，不采用。
- 直接切换正式 Web 后再补 0025/Worker：会让新代码读取缺列或遭遇旧预览协议，不采用。
- 为验证备份向正式库恢复或复制测试库：有数据替换风险，不采用；只在本机新实例恢复和演练。
- 清空测试订单或旧 Key：不属于本轮发布依赖，不采用；审计、账号及权益按既有规则保留。
