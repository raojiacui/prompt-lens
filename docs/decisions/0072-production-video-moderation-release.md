# ADR 0072：将已测试的视频审核与动态词库发布至主站

- 日期：2026-11-18
- 状态：负责人已授权正式站同步；本地验证、正式库迁移与审核凭据存在性核验完成，Git 发布核验中。
- 关联：ADR 0069、0070、0071。

## 背景

负责人确认测试站测试通过，并明确要求同步主站。测试代码仅按测试 Vercel 项目 ID 启用，直接推送不会开启正式审核。主站分支另有独立定价页、完整 AUP 和 Infistar 修复，必须保留。主站尚无审核数据库表，且 Vercel 实读未配置 Google 与 Waffo 审核凭据。

## 决策

- 从主站最新 `origin/prompt-lens-V2`（82a4d9d）创建本地 `codex/release-moderation`，合并已测试 `staging/v2`。逐文件解决审核入口及进度冲突；保留主站独立定价页、导航、公开访问、完整政策和 Infistar 修复，不用测试分支覆盖主站目录。
- 共用纯项目判断：测试项目保持既有审核，正式项目 `prj_LA38e0saqqVw1OkQ95AyoMx5vjIV` 仅在 VERCEL_ENV=production 时强制审核。其他项目和正式项目 Preview 不扩大启用。Waffo 与输出审核、动态词库、审计和管理员接口使用同一判断，不能通过 optional enabled=false 或 semantic=off 绕过受管环境。
- 保留已测试的 BYOK、平台付费输出审核、失败关闭及人工复核规则；Google 检测范围仍为画面中的成人内容。沿用现有私有 GCS 临时对象前缀 `prompt-lens-test-output-review/` 以兼容已配置生命周期清理；对象 UUID 避免覆盖，前缀不承载环境身份或访问权限。
- 在独立正式 Supabase `vxlwqiohliynbtjwivte` 应用完整 0026：两张服务端专用表、RLS、撤销浏览器角色权限、11 条基线规则。不迁移测试词、人工备注或审核记录，不修改旧业务表和历史迁移账本。
- 更新中英文隐私披露以覆盖正式站的 Waffo、Google 视频字节/私有 GCS 传输、审核日志和检测边界，移除后台仅测试站文案。
- 运营者在主站 Production 中配置 Google 服务账号、GCS 桶和 Waffo 商户凭据。测试变量为 sensitive，接口不能取回明文，因此不尝试从测试运行时导出密钥。正式配置缺失期间不得推送启用审核的正式发布，以免所有视频生成被失败关闭。
- 配置与验证就绪后，仅 Git 推送主站既有发布分支 prompt-lens-V2，由其 Git 集成构建主站。不使用 CLI 上传或手动提升，不推送 main 或改变测试站跟踪分支。

## 备选方案

- 直接将 staging/v2 覆盖正式分支：丢失主站新改动，且项目门禁仍只对测试生效，不采用。
- 凭据缺失仍先发布：会阻断正常生成，不采用。
- 删除审核门禁或关闭功能来让验收通过：违反目标行为，不采用。
- 复制全部测试数据库：混入测试任务、权限和词库数据，不采用。

## 影响

正式站新生成视频在明确审核允许前暂缓展示，审核服务或审计故障会暂缓交付。原已交付数据不批量改写；现有状态接口查询未获审核批准的历史生成记录时也会进入原审核逻辑，旧供应商任务是否仍可查询需结合实际任务判断。此前已经交付或分发的链接无法通过这次迁移追溯撤销，不能宣称历史内容已全量重审。

审核可能增加延迟及 Google 调用/临时存储费用；不改套餐、支付开关、模型选择、权益和邀请名单。Waffo 测试支付接口仍仅允许原测试项目，正式站不开放沙盒支付或新收款入口。

## 验证计划与本地结果

- 11 个相关测试文件共 79 项通过，覆盖正式/测试/Preview 项目门禁、强制 semantic、缺凭据失败关闭、真实 PGlite 审核记录及删除事务、全量空库迁移、生成进度、主站定价页与 Infistar 回归。
- 首轮发现空库表数测试仍为 38（现为 40），以及旧测试允许在测试站显式跳过审核；依据新增表及强制门禁更新断言后重跑全部 79 项通过，未删测试或关闭产品功能。
- TypeScript、修改源码 ESLint、差异检查及 Node 24.13.0 生产构建通过。构建使用不可用的隔离数据库连接，未读取正式业务数据；现有 GitHub OAuth 凭据缺失警告仍是该登录提供商的验收待办，未关闭提供商绕过。
- 正式 Supabase 项目通过项目列表与既有 ADR 身份核对，迁移前 38 张 public 表且无两张审核表。已应用 production_moderation_controls（完整 0026 SQL），现为 40 张；11 条初始规则、0 条审核记录，8 个审核索引有效，RLS 开启，anon/authenticated 无两表所查权限。
- 数据库 advisor 返回全部 40 张服务端表无浏览器策略的 INFO，符合现有架构；另有既有 public 扩展 WARN，未因审核迁移添加或移动扩展。说明：https://supabase.com/docs/guides/database/database-linter?lint=0014_extension_in_public 。
- 主站 Vercel 实读仍缺 Google 和 Waffo 审核变量，已通知负责人通过控制台设置；未推送正式发布，当前正式域名部署保持不变。配置存在性、Git 发布与域名 SHA 核验待完成。
- 负责人已口头确认原测试站测试通过；这不是本轮正式环境真实视频、付费交付或所有登录提供商的端到端证据。部署 READY 与配置存在不计作完整业务验收。
