# ADR 0067：公开政策页面与支付审核准备

- 日期：2026-11-14
- 状态：本地验证通过，待负责人确认发布；尚未推送。
- 关联：ADR 0039、0044、0063、0066。

## 背景

负责人已向 Dodo Payments 提交正式站 https://prompt-lens.cc.cd 的个人商户申请。截图显示身份批准、产品和银行资料已记录，仍在整体审核；负责人确认首页反馈来自真实用户。只读检查发现正式站 /terms、/privacy、/refund 均为 404，页脚无完整政策链接。Dodo 的网站准备要求未登录访客能读取价格、条款、隐私、退款及联系信息，负责人要求补齐缺项。

参考：https://docs.dodopayments.com/miscellaneous/verification-process#preparing-your-website 及 https://docs.dodopayments.com/miscellaneous/merchant-acceptance 。这是政策资料准备，不构成平台审核通过或支付端到端验收。

## 决策

- 增加 /terms、/privacy、/refund 的中英文公开页面，沿用语言 Cookie 和网站样式，提供互相导航、独立标题和 canonical、客服邮箱及退款工单链接。
- 共享页脚增加三个入口。政策正文服务端渲染，不读取会话或业务数据库；阅读不要求登录。
- 邀请测试限制仅对三个精确政策路径豁免。工作台、业务 API 及这些路径的下级地址仍走原邀请与认证控制，不变更邀请名单。
- 内容以源码中实际实现为依据：一次性套餐且无自动续费、现有待开放状态、按成功交付结算、部分成功结算、自带 Key 供应商费用边界、整单未使用权益退款申请和人工审批、退款期间冻结权益、拒绝后恢复、原渠道处理及不确定结果继续核查。
- 隐私披露第三方登录、加密保存并在调用时解密 API Key、创作素材传输、IP/浏览器/访问标识及统计、托管/存储/模型/解析服务商及境外处理、七天素材和生成历史规则、财务记录另行保留、删除请求需人工核验且没有自助注销。
- 条款面向18岁以上用户，明确素材授权、AI 输出边界、禁止冒充/深伪/侵权等用途及举报申诉入口。内容政策不声称已有全量自动审核，也不虚构 Dodo 已启用、即时退款或供应商的数据训练承诺。
- 不改支付、模型、套餐开放状态、退款算法、账户权限和数据保留任务，不新增真实支付调用，不向外发送邮件。本次仅完成本地验证及提交，等负责人确认发布。

## 备选方案

- 仅在登录后放政策：审核人员及购买前用户无法读取，不采用。
- 照搬其他平台合同及新增固定退款期限：可能与当前实现及负责人确认规则冲突，不采用。保留法定消费者权利，人工联系核查，不添加无依据的免责或地区仲裁条款。
- 先宣布支付已通过或直接接入新网关：超出本次范围，继续保持审核、资金交付与基础资料准备的证据边界。

## 影响

用户可在购买及登录前了解数据流向和退款路径。个人商户仍需完成产品、银行及合规审核；本站政策无法替代供应商审核或法定义务。涉及个人运营身份、隐私及退款的正式文本需负责人阅读确认。推送 V2 会触发正式与测试两站 Git 构建，必须获得本次发布确认。

## 验证计划

- 类型、修改源码 ESLint、差异检查。
- 回归邀请访问控制：精确政策路径匿名通过且保留安全头及语言处理，下级路径、工作台和业务 API 仍受限。
- 隔离浏览器验证中英文、手机及桌面，三个页面 200、服务端正文、页脚和互链、正确标题及 canonical、无横向溢出；检查手机和桌面截图。
- 不连接正式数据库，不创建订单或调用真实模型。预览截图及临时测试配置不提交。

## 本地验证结果

- Node 24.13.0；TypeScript 检查、全部修改产品源码 ESLint 与 git diff --check 通过。
- 邀请访问控制 Vitest 回归 13 项通过，包括三个精确政策路径匿名放行、下级路径仍跳转登录、业务积分 API 仍返回 401，以及原会话恢复规则。
- Playwright 4 组通过：中英文 × 390/1440 像素，每组检查三个政策页面，共12次页面访问均200。标题、canonical、互链、页脚入口、公开客服邮箱、正文及无横向溢出检查通过；手机中文及桌面英文截图已查看。
- 浏览器预览使用独立4116端口、不可用的隔离数据库地址、专用测试认证密钥及原四个邀请邮箱；浏览器会话和访问统计接口为本地夹具。未使用正式会话、正式数据库、真实支付或模型服务。
- 临时配置首次启动时工作目录错误，修正为仓库根目录后重跑通过。没有修改产品功能来绕过测试；未执行本地生产构建或线上验收，线上政策地址须待获授权的 Git 发布后复查。
