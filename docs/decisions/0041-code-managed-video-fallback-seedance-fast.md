# ADR 0041：底层缺省视频模型采用代码中的 Seedance 2.0 Fast

- 日期：2026-11-09
- 状态：已确认，实施及验证结果见下方。
- 关联：ADR 0040、上线记录第 010 项。

## 背景

页面已有 Seedance 2.0 Mini 默认值，正常提交会显式携带选中模型。较底层视频 Provider 仍支持 KIE_VIDEO_MODEL 环境覆盖及 Wan 缺省值。负责人认为额外备用配置无必要，允许删除或改成 Seedance 2.0 Fast；隐藏环境覆盖也容易使代码声明与实际行为不同。

## 决策

- 保留页面代码管理的 Mini 默认值，及用户显式模型、草稿和做同款模型选择。
- 底层未收到模型时采用固定 DEFAULT_KIE_VIDEO_MODEL=bytedance/seedance-2-fast，替换原 Wan 缺省值，并删除 KIE_VIDEO_MODEL 环境变量读取及示例项。同步更新内部导出与引用，移除旧常量名。
- 该值只用于没有模型参数的备用路径，不捕获推理失败、不自动改模型重试，不替换已确认报价快照中的模型。
- 不改正式或测试环境变量、密钥、价格、模型注册表、自动路由策略、Worker 或数据库。旧环境项不再被此代码读取，不能继续覆盖该备用值。
- 按既定流程本地验证、提交，推送 GitHub V2，由测试项目 Git 集成部署；正式 Web 切换仍按上线窗口另行授权。

## 替代方案

- 删除全部备用行为并强制缺模型报错：可行，但需改变调用契约及错误行为，本次采用负责人允许的 Fast 备用方案。
- 保留环境覆盖、仅改字符串：已存在的 Wan 或隐藏值仍会优先，不能确定实现本次确认的备用行为，不采用。
- 将页面默认改为 Fast：不符合负责人明确的 Mini 页面默认要求，不采用。

## 后果与验证计划

- 缺省模型由代码追踪，环境项不再成为这处行为的来源；页面普通生成仍采用显式 Mini 或用户所选模型。
- 使用既有素材路由和工作流测试验证视频请求契约，并执行本地生产构建；不调用真实付费模型或为此创建用户任务。
- 推送后核对远端 V2 SHA、测试项目 Git 来源部署 SHA、固定测试域名及正式站部署 ID；不通过 CLI 上传或手动提升部署。
- 本次不将发布成功等同于真实模型交付验收，COMMERCIAL_MODEL_ACCEPTANCE 保持原状态。
