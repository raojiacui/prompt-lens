# ADR 0076：补齐 Waffo 复审要求的举报与申诉处理时限

- 日期：2026-11-19
- 状态：获授权的主站 Git 发布及中英文线上条款核验通过；Waffo 重新提审尚未执行。
- 关联：ADR 0067、0072。

## 背景

Waffo 审核反馈确认现有 AUP 禁止内容、处置措施和举报渠道已列明，但缺少收到举报或申诉后的明确核查和反馈时限。负责人要求整改，并明确选择“3 个工作日内完成初步核查并反馈”。

参考：https://docs.waffo.ai/zh/mor/account-reviews/aigc-compliance 及其 AUP 模板。截图中的具体整改要求是本次修改依据；不将模板示例的小时级 SLA 当作本产品现有承诺。

## 决策

- 中英文服务条款第 5 节明确：收到举报或申诉后 3 个工作日内完成初步核查，并经原客服渠道或联系邮箱反馈初步结果及已采取措施。
- 可结案的同时告知结论；复杂、需补材料或联系第三方的案件，同样在 3 个工作日内说明待补材料、当前进展、延期原因和预计完成时间，核查完成后反馈最终结果。工作日不含周末及中国大陆法定节假日，不虚构统一的最终结案期限或全天候团队。
- 继续使用页面现有公开客服邮箱，保留隐私保护、权利证明和原处置措施。无需用户登录，不添加新的举报表单或改变审核判定流程。
- 同步修正过期的“独立审核尚未上线”描述，准确说明动态词库、Waffo Prompt Sift、Google 视频成人画面检测、未批准结果暂缓展示及人工记录，保留检测范围限制。
- 政策更新日期改为 2026-11-19。当前只完成修改、验证及本地提交，不替用户重新提交 Waffo 商户申请。

## 备选方案

- 只写“尽快处理”：缺少可预期时限，无法回应本次反馈。
- 套用模板中 2 小时、24 小时等分级承诺：未获负责人确认且缺少实际运营保障，不采用。
- 承诺所有案件 3 个工作日最终结案：第三方取证可能超出可控范围，负责人确认的是初步核查与反馈，采用明确延期说明机制。

## 影响及验证计划

这是运营承诺，负责人需持续查看公开支持邮箱并按期限完成初步核查和反馈；政策文字更新本身不代表 Waffo 已通过复审。

执行 TypeScript、修改源码 ESLint、差异检查；用隔离本地浏览器核对中英文、手机及桌面公共政策页，验证时限、适用举报和申诉、延期说明和正确审核披露。待负责人要求发布后再验证正式站正文，保留本次审核退回与后续复审结果的区别。
