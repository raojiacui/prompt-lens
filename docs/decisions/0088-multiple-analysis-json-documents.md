# ADR 0088：同一分析响应中的失败草稿与有效修正

## 背景

2026-11-28 测试站图片分析记录报 JSON.parse 在第一段 JSON 结束后读到额外字符。用户提供同一画面的一段不可读草稿及一段有效分析。现有图片路径仅提交一次请求，不能仅凭两段文本认定应用进行了重试。原解析器截取首个左括号至最后一个右括号，将多段 JSON 合并为非法文档，导致已有有效描述仍显示失败。

## 决策

对带图像输入的场景响应，按字符串、转义和对象嵌套边界提取完整 JSON 文档，逐份执行既有结构与视觉有效性校验。只有一个明确有效结果时采用它，允许完全相同的重复结果；多份有效但不同、尾部截断、全部无效均拒绝。限制响应长度及候选数。无图文本、改写等流程保持原协议。

不把失败草稿写为成功，不随意取最后一段，不将半截 JSON 补齐。恢复同一已完成响应中的有效内容无需新增供应商调用，沿用已存在的任务存储与计费校验。

## 备选与后果

直接再次调用模型会增加费用；无条件选择最后对象可能选到元数据或冲突场景。边界扫描保留有效画面，又让不确定输出继续明确失败。已保存为失败的历史任务不会因代码升级自动恢复，不使用用户粘贴内容覆盖线上分析或补扣费用。

## 验证计划

本地复现连续和带代码围栏的双 JSON，校验失败草稿后有效结果可恢复、字符串括号与转义保持原样、冲突和截断被拒绝。通过实际图片分析函数断言一次 mock 请求即可得到有效结果，不产生真实供应商费用。按 Git 测试分支规则发布，主站发布继续等待明确授权。
