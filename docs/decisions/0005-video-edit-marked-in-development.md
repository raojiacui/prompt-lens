# ADR 0005：视频剪辑入口标记为开发中并禁用

- 状态：已采纳
- 日期：2026-10-24

## 背景

Dashboard 已展示“视频剪辑”标签，并会在点击后加载完整剪辑界面。该功能目前仍在开发，不适合让主站用户进入和使用。

## 决策

1. 保留“视频剪辑”标签，向用户展示该能力正在建设。
2. 标签使用原生 `disabled` 属性禁止点击，并显示本地化的“开发中 / In development”状态。
3. Dashboard 移除 `VideoEditTab` 的导入和渲染，避免禁用状态被绕过时加载未开放界面。
4. 保留剪辑组件和服务端实现，供后续开发与测试继续使用。

## 备选方案

### 完全隐藏标签

界面更简洁，但用户无法得知该能力正在开发，产品预告效果较弱。

### 点击后展示开发中页面

需要用户先进入无可用操作的页面，增加一次没有收益的交互，因此不采用。

### 删除剪辑功能代码

会中断正在进行的功能开发，并扩大本次改动范围，因此不采用。

## 影响

- 主站用户可以看到视频剪辑功能及开发状态，但无法点击进入。
- Dashboard 客户端不再加载视频剪辑组件。
- 后续正式开放时，需要恢复组件导入和渲染，并移除标签的禁用状态与开发中标记。

## 验证计划

- 测试中校验中英文状态文案、标签禁用属性，以及 Dashboard 不导入或渲染 `VideoEditTab`。
- 运行 TypeScript 检查、非 E2E 测试集和 Next.js 生产构建。
