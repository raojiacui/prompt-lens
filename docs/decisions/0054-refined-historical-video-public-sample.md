# ADR 0054：将十七镜头古风短片加入公开样例

- 日期：2026-11-12
- 状态：已发布 V2；正常登录会话下的线上页面验收待确认。
- 关联：ADR 0053、0030、0026。

## 背景

用户确认拆镜优化效果后，要求将同一条视频放到样例页面。最新已完成任务为 `2290f5b6-dab2-47a0-9d9d-40c025122f48`，项目 `679cfc78-2ba8-49c1-a47a-614f0c83ecfe`，版本 `8fa95389-c319-45c6-ab95-3023bef3a88d`，含 17 条成功保存的原始分析，失败镜头为零。

## 决策

- 沿用静态白名单样例快照，标题和展示文件名按用户指定改为“荆轲刺秦王”，置于列表首位；替换初次发布的临时标题。保留 17 条真实原始分析和原始时间轴空隙，不再次调用模型或修改提示词。
- 只读核验任务归属、完成状态及当前版本一致性；只导出展示所需字段，剔除账号、任务、密钥指纹、执行、存储键、源哈希及诊断信息。原账号项目、积分与任务保持原样。
- 复用已有公开视频、片段、关键帧及音频，继续由现有公开样例媒体引用保护机制防止过期清理。缺少独立片段的镜头使用同源视频的 `#t=开始,结束` 预览，沿用既有样例策略；不伪造关键帧或补写源记录。
- 发布前逐一核验媒体的存储 HEAD 与公开 HEAD；只通过 `prompt-lens-V2` 的 Git 集成发布 V2 测试站，正式站保持原部署。

## 备选方案与后果

直接开放原项目查询会扩大隐私暴露范围并受后续账号操作影响；重新分析会产生额外费用并改变内容。沿用固定的脱敏快照，使样例稳定可复现，媒体继续占用既有存储。公开样例的后续更新需要显式修改快照。

## 验证计划

- 17 个镜头均有真实有效提示词，编号 01–17、原第 5/6 镜头的合并区间为 6.583–8.458 秒，保留 7 处黑幕时间空隙。
- 样例列表和详情、媒体保留与隐私字段回归通过，类型检查通过；核验每个公开媒体对象可读取。
- 发布后检查远端 SHA、Git 来源部署 SHA、固定测试域名和公开样例接口，并确认正式站部署 ID 未变。

## 本地验证结果

- 新样例含 17 个完成镜头和 17 条原始有效提示词，样例总数增至 12。第 2、7、9、16 镜头沿用同源视频时间段预览，其他镜头复用已有独立媒体。
- 66 个独立媒体对象全部通过存储 HEAD 和公开 HEAD；没有新增媒体执行或模型调用。参考视频的公开时长使用已完成任务内的精确探测结果 29.792 秒，保留账号中原有的整数时长记录。
- 样例、媒体保留和视频概览共 27 项回归通过，TypeScript 检查通过，内部字段排除检查通过。只新增公开快照与目录条目，未改账号数据或余额。
