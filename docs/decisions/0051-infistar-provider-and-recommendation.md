# ADR 0051：Infistar 自带 Key 接入与推荐入口

状态：实现中；真实模型能力与全流程验收待验证。

## 背景

V2 新增 Infistar 供应商，在首页、配置页和 README 使用 PromptLens 专属注册链接；配置页新增模真真外链。KIE 模型清单保持不变；用户后续明确授权 Infistar 侧按可用模型和成本调整，优先可灵与即梦系列。品牌 Logo 由用户补充，收到前使用品牌文字。

## 决策

- 配置展示顺序为 Infistar、KIE，Infistar 标注“推荐”。不展示商务合作标识。
- Key 在明确的供应商配置项保存，记录 provider，沿用现有服务端加密。禁止根据 `sk-` 格式猜测归属或将 Key 向多家接口试探。
- 新增独立首选标记及每用户唯一约束；已有 KIE 账户保持原供应商，只有显式切换才改用 Infistar。修改偏好不影响历史任务，报价、后台执行和查询都固定供应商与 Key 指纹。
- 平台试用、付费平台 Key 继续使用 KIE，保留邀请白名单、权益检查和计费流程；Infistar 用于用户自带 Key 的全功能调用。
- 通过 Infistar 真实模型列表及官方公开价格核实可用 ID。Infistar 配置独立模型清单，优先可灵 O1、Seedance 2 Mini/Fast 和 Wan 2.7；实际调用型号清晰显示，禁止按原名称静默替换。未明确支持的参数在提交前报错，能力缺口作为验收阻塞记录。
- 用户明确授权真实联调累计费用不超过人民币 5 元，仅消耗既有余额，不充值。测试 Key 只保存在 Git 忽略的 `.env.local`，日志与提交禁止包含密钥。
- 首页顶部公告可关闭，通过版本化本地标记记忆关闭状态；README 顶部展示产品品牌，推荐表格左品牌、右介绍与链接。
- 注册入口统一为 `https://www.infistar.cc/register?aff=PROMPTLENS&ref_source=link`，文案提供人民币 5 元 API 体验额度。
- 模真真入口为 `https://mozhenzhen.com/verify`，新标签页打开，不携带用户 Key。

## 替代方案

1. 根据 Key 前缀自动识别：供应商之间格式不唯一，拒绝。
2. 配置多个供应商后自动轮询或故障转移：可能重复扣费、跨平台泄露凭据，拒绝。
3. 原先保留所有供应商相同模型：真实清单无法覆盖；用户补充授权后改用分供应商模型清单，保留 KIE 原配置。

## 后果

需先运行数据库迁移 0025，再启用新代码。供应商能力差异需要逐模型联调；模拟测试通过不能表示线上功能验收通过。没有应用迁移、未提供的品牌资产及未完成的真实调用均需在交付中说明。

## 验证计划

- 验证加密兼容性、保存/切换的鉴权及同源限制、偏好兼容与供应商隔离。
- 验证分析、改写、视频生成/编辑、音频、Agent 的路由、后台恢复与历史查询。
- 对照真实 `/v1/models` 返回核实模型 ID，验证用户指定模型和参数不被替换。
- 本地测试、类型检查、构建及移动端/桌面界面检查；每个模块本地提交。此次不推送、不部署。
