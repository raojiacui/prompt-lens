# ADR 0074：统一分析与生成页的自带 Key 供应商展示

- 日期：2026-11-18
- 状态：本地验证及获授权的主站 Git 发布完成。
- 关联：ADR 0061。

## 背景

负责人指出分析页费用来源只显示“自带 Key”，而生成页显示供应商名称，要求两页一致。`/api/credits/me` 已返回实际选用凭据的 byokProvider，分析页未声明或展示此字段。

## 决策

- 两页共用 ownKeyPaymentLabel，根据 credits/me 的 byokProvider 展示“自带 Key · Infistar”或“自带 Key · KIE”，英文使用“Own key · …”。
- 数据加载中或供应商未知时显示通用“自带 Key”，不根据模型猜测或提前显示 KIE。
- 保留现有选择框样式、选择状态和禁用条件，不改变凭据路由、计费及报价快照规则。

## 备选方案

只在分析页复制生成页的分支表达式容易导致两页以后再次分歧，故提取共用文案函数。修改后端响应没有必要，现有接口已提供供应商字段。

## 影响与验证

改动仅涉及费用来源选项文案和类型声明；不读取 API Key 内容，不增加请求。TypeScript、修改源码 ESLint 和差异检查通过；同时移除分析页原有未使用的 catch 参数。此记录不代表已经发布。
