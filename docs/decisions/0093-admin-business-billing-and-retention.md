# ADR 0093：管理员使用普通计费，仅豁免素材和历史到期清理

日期：2026-11-28。状态：已完成本地实现，发布及完整验收进行中。

## 背景

用户希望用自己的管理员账号验证真实消费流程。原有管理员平台 Key 免扣、无限试用和容错回退会掩盖普通用户的计费问题；同时七天清理会删除用户希望长期保留的分析历史。

## 决策

保留管理员身份和后台管理权限，业务消费与普通账号一致：平台积分经过报价、预留和结果结算，自带 Key 使用用户保存的首选供应商，缺少或解密失败时不得回退平台 Key。取消管理员无限试用和免费平台执行。新请求统一规则，不补扣历史已完成的免费任务，不修改用户余额。

管理员唯一的内容保留例外是免自动到期清理：项目原始素材、镜头、关键帧、分析结果和生成历史保留。保留身份依据与服务器管理员身份相同的已验证站长账号，不信任客户端角色或任意 `role=admin`。普通用户仍按七天规则执行，活动任务和公共样例继续受既有保护。手动删除项目保持可用，服务商托管视频链接的有效期仍由服务商决定。

清理候选筛选和事务锁后复查都排除管理员项目；生成历史清理及读取过滤同步豁免；R2 清理保护管理员仍保留的完成任务输入。项目已被手动删除时，已完成任务的 JSON 中旧项目 ID 不阻碍删除对应文件。不会恢复已删除或已被服务商回收的历史内容。

## 备选方案

临时换普通账号测试无法覆盖用户本人常用工作流；只改界面仍会命中后端免扣；只保留分析数据库记录会留下失效素材链接。采用业务计费统一和内容保留例外的完整路径。取消管理员后台权限会超出请求范围，不采用。

## 影响和验证

需要更新既有管理员免扣测试，加入平台积分成功结算、失败释放、自带 Key 隔离、余额不足及试用上限的验证。保留策略使用隔离数据库验证管理员过期内容及完成输入副本保留、普通账号仍清理、显式删除仍生效；生成历史读取及清理专项目前 17 项通过。

不修改线上余额或账号角色。发布时继续选择性合入主站，不带入未发布的脚本工作台；线上验证不未经授权产生额外模型费用。

已删除新请求的 `admin` 业务计费模式、`platform_admin` Key 授权、无限试用及相关错误吞掉后继续使用平台 Key 的逻辑。历史生成任务状态查询保留对旧 `platform_admin` 快照的只读识别，以便查询已存在的供应商任务，不授予新的免费执行。分析和报价前端不再判断管理员免扣，管理员同样先确认平台图片报价；自带 Key 仍明确绑定首选供应商。

管理员普通计费、首选 Key、图片成功扣费、缺少 Key、试用上限和真实页面交互专项 57 项通过。素材和生成历史保留专项 17 项通过；完整回归及生产构建结果在发布后补记。
