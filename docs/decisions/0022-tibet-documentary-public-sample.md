# ADR 0022：将“西藏人文纪录片”分析加入 V2 样例

- 日期：2026-11-03
- 状态：已采纳，沿用既有只读样例快照，发布验证见后续记录。
- 关联：ADR 0013

## 背景

用户要求将最新一条分析结果放入样例页，指定标题为“西藏人文纪录片”。V2 账号最新完成的项目为 `bad27466-22a9-43d8-9f7e-ae0d0182dcac`，当前分析版本 `2e193842-0395-4088-9e0c-681d50d6b619` 有十个镜头，内容包括高原雪山、藏式民居和牧民生活。同一版本还有一次森林木屋改写，属于后续测试内容。

## 决策

- 将十个镜头最近有效的原始分析加入公开静态快照和样例目录，标题为“西藏人文纪录片”，排在样例列表首位。排除后续改写，不重新分析、不调用模型、不修改账号原项目和额度。
- 只导出展示所需的项目、版本、镜头、分析和媒体字段。使用明确字段白名单清除账号、任务、执行、存储键和诊断信息；公开源文件名为“西藏人文纪录片.mp4”。
- 沿用公开样例媒体引用和清理保护机制。所有引用使用固定公开地址，导出前逐一验证存储对象和公开 HEAD，拒绝临时签名 URL。
- 第 3、5、9 镜头原始记录没有独立片段和关键帧；仅在公开快照中将其预览地址设为原视频 `#t=开始,结束` 时间段，不伪造关键帧、不重新生成或修改源记录。公开分析不包含生成测试视频。
- 仅通过推送 GitHub `prompt-lens-V2` 自动部署到 `prompt-lens-v2-test`，发布前核对项目绑定和活动任务，发布后核对测试域名提交及正式站部署未变。

## 备选方案

- 直接公开原项目查询：会随账号编辑改变，并增加内部字段泄露风险，继续采用静态快照。
- 展示最新改写结果：首镜头已变成森林木屋，与纪录片源素材不一致，因此收录原始分析。
- 再次调用模型生成样例：会额外消耗模型费用且改变现有内容，不采用。

## 后果

样例固定保留这次原始分析，后续修改需要显式更新快照。视频、镜头、关键帧和音频因公开样例引用继续保留并占用存储空间。账号原项目保持私有，公开范围仅限此快照白名单字段和已核验的媒体。

## 验证计划

- 样例列表及详情显示指定标题，十个镜头均为已完成的真实分析，每个原始镜头仅保留一个分析版本，无森林改写及内部账号/任务字段。
- 所有公开媒体通过存储和公开 HEAD 核验；样例回归及类型检查通过。
- 核对远端 V2 提交、Git 来源自动部署、固定测试域名及正式站部署不变。用户本次授权公开样例，不据此标记其他模型流程端到端验收通过。
