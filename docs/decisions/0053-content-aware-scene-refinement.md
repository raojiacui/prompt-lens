# ADR 0053：拆镜后校验画面连续性并排除空白转场

- 日期：2026-11-12
- 状态：已实现、通过本地验证并发布 V2 测试环境；2026-11-13 按负责人另行授权，正式 Worker 已更新为同一镜像并通过合成媒体探针。正式 V2 Web 尚未切换，执行证据见 ADR 0062。

## 背景

用户的 29.79 秒测试视频被拆为 24 段，其中 7.792 秒的切点把连续的人物运动拆成两段。AdaptiveDetector 的 HSV 帧间变化在重复帧附近产生了相对峰值。视频后半段还包含多次模仿眨眼的纯黑转场，原检测器将其当作普通镜头，其中最后一段黑幕和后续实景还被合在同一段中。

## 决策

1. 保留现有 PySceneDetect 主检测器及 FFmpeg 回退。在两者之后统一执行本地 `scene-refine.py`，使用 FFmpeg 显式选择已验证的视频流并读取逐帧 PTS，避免固定帧率估算导致时间漂移。Docker 与构建上下文必须包含该脚本，主检测器固定为本地验证使用的 `scenedetect-headless==0.7.1`，避免本次重新构建意外升级检测器。校验失败返回 `SCENE_DETECTION_FAILED`，不得通过回退绕过过滤。
2. 对接近纯黑或纯白的整帧同时检查 RGB 距离均值、方差及连通的前景标记。暗场、亮场、彩色纯色、带标题或标识的黑白底画面继续保留。分析图缩放至 640×360；极小、极低对比度内容存在检测极限，保守保留边界上的压缩噪声与淡入画面，不能声称能够识别任何尺寸的内容。
3. 从原始时间轴扣除确定为空白的连续帧区间；保留时间空隙，不拼接时间、不让黑幕重新并入相邻镜头。短于原最短镜头时长的真实画面仍可保留。空白边缘 0.12 秒内的候选切点并入相邻内容，防止取整或淡入产生碎片；不删除这些真实帧。长镜头的既有 8–10 秒切分规则保持生效。
4. 只有前后图像高度相关、变化范围有限，并存在足够比例且分布在多个区域的双向光流跟踪点时，才移除候选切点。颜色或直方图相似不足以证明是连续镜头。该策略保持保守，不能保证消除所有运动误切或识别所有语义镜头。
5. 自动拆镜全为空白时返回 `NO_USEFUL_SCENES`，显示明确提示，不创建分析报价或预留积分。用户明确选择整段分析时继续保留完整视频。过滤后的镜头使用原始微秒区间报价和截取；拆镜服务仍按原视频时长计价，选中镜头的分析时长按保留内容计算。两个拆镜入口的素材均精确重编码，移除旧入口的 GOP 流复制分支；截取保留微秒精度并对排他结束边界减去 1 微秒，避免四舍五入后带入下一帧黑幕。
6. 新自动预览使用 `content-scenes-v3` 缓存版本，并检查 Worker 返回的版本。旧预览不再用于新的同源拆镜请求；已有预览、报价及其截图和计费快照继续按原保留期有效，不修改历史记录。手动整段预览继续原有缓存策略。无需数据库迁移。线上 FFmpeg 5 的 `pts_time` 仅输出六位有效数字，初次线上核对后已改用整数 PTS 乘 time_base 计算精确时间，并再次提升缓存版本，避免沿用取整时间。
7. 本次验证只使用本地处理、合成素材、只读下载及隔离数据库，不调用收费模型，不触发实际分析。发布仅使用独立测试 Worker 和 `prompt-lens-V2` 的 Git 自动部署；正式 Worker 和正式 Web 保持原部署。

## 备选方案

- 提高全局切镜阈值：可能同时漏掉真实切镜，无法解决黑幕混入片段的问题，不采用。
- 只检查每段中间一帧或平均亮度：容易误删暗场、片头字幕，并漏掉与实景混合的黑幕，不采用。
- 仅删除整段黑幕：最后一段黑幕被合入实景，仍会残留；采用逐帧空白区间扣除。
- 用视觉模型重新判断全部镜头：增加费用、延迟及不可重复性；本轮采用可复现的本地处理。

## 后果

每次新自动拆镜增加一次低分辨率解码和少量候选切点光流计算。内存按帧流式使用，不缓存整段视频。有效镜头的时间轴允许有空隙，现有报价、选镜、下载和素材截取均需按精确区间处理。`trim` 在输出时间戳归零之前限制排他结束边界，单独使用输出 `-t` 仍可能在取整起点处多带一帧。旧报价不会自动改变，新的预览需要重新进入拆镜流程。

## 验证计划及证据

- 原视频本地复现：原 24 段；新主检测器链路为 17 段；仅移除 7.792 秒候选切点，6.583–8.458 秒合为一段。排除 7 段黑幕，原视频及场景时间位置不压缩。
- 完整本机 Worker HTTP 链路：主检测器 17 段；强制回退隔离测试 16 段，保留回退检测器原有精度差异，但同样排除 7 段黑幕。手动整段保持 1 段完整时长。只下载素材，未写入 R2 或业务库。
- 合成测试覆盖黑/白帧及压缩噪声、黑白底文字和小标识、暗场和高亮细节、相似色彩的不同画面、连续运动、原始时间空隙、短镜头及实际 FFmpeg 解码。
- 既有 464.80 秒人工标注素材回归：78 个候选切点全部保留，没有误删原切点或误判空白。原基线 F1 0.7394 保持不变；此项只证明该素材没有退化，不代表整体检测准确率提升。
- 本地实际截取原视频 18.833–19.416667 秒片段，修正后解码为 14 帧实景，逐帧过滤未发现黑幕；原来的输出时长限制会多包含第 15 帧黑幕。
- 缓存及隔离计费测试覆盖版本升级重新生成预览、旧报价不变、全空白失败不预留积分、Worker 版本不匹配拒绝接收。
- 本地 Python 18 项、Node 6 项、Vitest 206 项通过，隔离数据库中既有 1 项测试按原配置跳过；TypeScript 与 Next.js 构建通过。构建仍有仓库既有 lint 与本地 GitHub 登录凭据缺失警告，本轮没有修改或禁用登录配置。
- 发布后以真实测试 Worker 预览验证相同视频，不提交分析任务，并核对 Git 与部署 SHA、测试域名和正式站部署 ID。
