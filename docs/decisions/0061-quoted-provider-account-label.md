# ADR 0061：自带 Key 费用说明显示报价实际供应商

- 日期：2026-11-13
- 状态：本地验证通过，待 V2 Git 集成部署核验。

## 背景

用户配置无限星河 Key 后，分析费用页仍显示“模型费用由你的 KIE 账户承担”。后台已在报价任务中保存实际凭据供应商，但报价响应未返回该字段，前端说明直接写死 KIE；帮助页及首页定价说明也存在同类措辞。

## 决策

- 报价响应返回已用于任务快照的 `provider`；费用说明按报价字段显示“无限星河 Infistar 账户”或“KIE 账户”。显示和执行复用同一供应商来源，不根据模型名称推测，不读取其他账号凭据。
- 报价缺少有效供应商时显示“对应供应商账户”，避免把未知来源默认为 KIE。Key 缺失提示使用“所选供应商的 API Key”，沿用现有错误码兼容性。
- 帮助页和公开定价文案面向所有供应商，统一使用 API Key、供应商账户及余额的通用描述。平台积分、供应商余额及拆镜收费规则保持原样。
- 不改变凭据选择、任务路由、模型、计费或已提交任务的供应商快照，不新增模型请求。

## 备选方案与后果

仅将 KIE 字样替换为 Infistar 会反向误导 KIE 用户。始终使用当前设置名称会在报价与设置变更后产生歧义，故使用报价任务快照。历史兼容响应缺少字段时采用通用说明。

## 验证计划

- 隔离后台回归：分别保存 KIE、无限星河凭据，报价响应供应商与任务快照一致，整段自带 Key 仍为零平台推理积分。
- 实际页面浏览器回归分别验证两家供应商的账户文案，未确认报价不提交推理；完成类型和构建检查。
- 本地验证后独立提交、推送 V2 Git 分支，核对 Git SHA、测试部署及域名、正式站部署保持不变。

## 本地验证结果

- 两个测试文件共 148 项通过、1 项沿用原有跳过设置；包含两家供应商的后台报价／快照一致性和实际页面账户文案回归。
- `npm run build`（含类型检查）及 `git diff --check` 通过。测试使用隔离数据和模拟请求，未启动真实模型推理。
