# ADR 0058：免费试用默认 DeepSeek，进度文案区分整段与拆镜

- 日期：2026-11-13
- 状态：本地验证通过，待 V2 Git 集成部署核验。

## 背景

用户在整段分析时仍看到“拆镜分析”，并要求跟进新任务。后台只读核对任务 `35b04543-1f11-43d4-a10d-bb6dff99d71b` 的 longVideoAllowed=false，预览为 0–13.816 秒的一段完整区间；媒体服务收到 automaticSplit=false，未执行镜头检测。界面阶段标签被写死，造成误导。

日志确认这次平台 KIE Gemini 请求出现上游临时错误，重试后没有成功结果。用户确认后要求免费默认模型改用 DeepSeek。任务账号为 QQ，未保存个人 Key；无限星河 Key 属于另一个管理员账号。用户已确认此次使用免费试用次数，账号隔离及凭据路由符合预期。

## 决策

- 免费试用改用 KIE DeepSeek V4.1 Flash：界面模型 ID 为 `analysis-deepseek-v4-1-flash`，供应商模型 ID 为 `deepseek-v4-1-flash`。提取不包含服务端依赖的共享配置，同步免费选择器、请求参数、额度能力和后端强制路由。沿用已实现的 KIE Responses 多模态接口，不更改普通自动推荐或自带 Key 的供应商与已选模型。
- 状态接口返回任务真实分析模式，进度页按图片、整段视频或自动拆镜显示“图片分析／整段分析／拆镜分析”。历史进行中任务以后台模式为准，不根据当前表单猜测；去除未使用的旧阶段标签。
- Key 保持按账号隔离。免费试用用平台 Key；自带 Key 用当前账号保存的首选供应商，不能从管理员账号复制凭据到 QQ 账号。正常套餐、试用次数与邀请名单不变。
- 不重启已失败任务，不新增真实推理请求；原任务已由正常恢复流程收尾为 failed，chargedCredits=0，试用预约 released，trial_used=0。
- 在失败结果保存前记录经过脱敏的供应商错误和阶段错误，避免失败结果未落库时只剩成功/失败布尔值。日志不包含 Key 或媒体内容，不把未知结果当作成功。

## 备选方案及后果

只改页面名称会使实际免费请求继续使用 Gemini，因此前后端共用配置。修改全局 KIE 聊天默认模型会影响付费及已选模型，不采用。跨账号读取无限星河 Key 会破坏凭据隔离，不采用。新的免费试用执行改用 DeepSeek；原始失败任务及其历史模型快照保持原样。

## 验证计划

- 实际页面回归免费账户选中并提交 DeepSeek，自带 Key 用户的原模型选择保持不变；整段分析进度不包含拆镜标签。
- 后端免费模型锁定、供应商 Responses 协议、整段媒体请求 automaticSplit=false、历史任务模式接口及凭据读取回归通过，完成类型与构建检查。
- 提交后经 V2 Git 集成发布，核对远端 SHA、部署 SHA、固定测试域名和正式站部署 ID。验证只使用隔离夹具和现有任务的只读查询，不发送新模型请求。

## 本地验证结果

- 7 个测试文件、119 项测试通过，包含真实页面的免费试用 DeepSeek 提交、自带 Key 保持原模型、整段分析标签和进度轮询验证；网络请求全部由夹具拦截。
- `npx tsc --noEmit`、`npm run build` 和 `git diff --check` 通过。此次未新增真实模型推理或重跑原任务。
