# ADR 0075：展示 KIE 合作注册链接

- 日期：2026-11-19
- 状态：本地预览，等待用户确认发布。

## 背景与决策

KIE 推广合作已确定。README 合作伙伴表格在 Infistar 下方加入 KIE，品牌标识为左图右字。首页两条公告共用蓝色背景、品牌图标和注册入口，并可独立关闭。API Key 设置沿用现有供应商卡片，仅 Infistar 显示“推荐”。

三个位置使用用户提供的 KIE 专属链接。[KIE 官方 FAQ](https://kie.ai/#faq) 公布新用户可获得 80 免费试用积分。[公开推广计划入口](https://kie.ai/user/affiliate)未提供该链接专享加赠规则。页面仅展示免费试用积分数，注册链接单列。设置页与首页共用链接常量。

## 备选与验证

也可把两个伙伴放在同一公告中，但这会让不同注册入口和活动文案共用关闭状态。独立公告便于辨认并保留原有交互。用桌面和移动浏览器核对两条公告的链接、关闭行为与设置卡片，再提供 README 和页面的本地预览供确认。

本地 Chromium 的 6 项回归通过，涵盖桌面与手机首页，以及中英文 API Key 设置。README 本地渲染已核对 KIE 的 Logo、名称和注册入口均指向同一专属链接。
