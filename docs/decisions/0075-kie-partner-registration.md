# ADR 0075：展示 KIE 合作注册链接

- 日期：2026-11-19
- 状态：用户已确认发布到正式站。

## 背景与决策

KIE 推广合作已确定。README 合作伙伴表格在 Infistar 下方加入 KIE，品牌标识为左图右字。首页两家共用一条蓝色横幅，桌面并排，窄屏换行，两家各有独立注册链接，关闭按钮作用于整条横幅。API Key 设置仅 Infistar 显示“推荐”，KIE 的注册入口显示「专属注册 · 领取 80 积分体验额度」。

三个位置使用用户提供的 KIE 专属链接。[KIE 官方 FAQ](https://kie.ai/#faq) 公布新用户可获得 80 免费试用积分。[公开推广计划入口](https://kie.ai/user/affiliate)未提供该链接专享加赠规则。页面仅展示免费试用积分数，注册链接单列。设置页与首页共用链接常量。

## 备选与验证

独立公告会重复品牌标识并占用更多首屏空间。合并后用桌面和移动浏览器核对两家注册链接、排列方向、整条横幅关闭与重访行为，以及设置卡片文案。

本地 Chromium 的 6 项回归通过，涵盖桌面与手机首页，以及中英文 API Key 设置。README 本地渲染已核对 KIE 的 Logo、名称和注册入口均指向同一专属链接。

## 发布

用户确认正式站跟踪 `prompt-lens-V2`，测试站跟踪 `staging/v2`。本次从 `prompt-lens-V2` 触发正式站 Git 自动部署，并核对远端提交、部署来源与正式域名指向。
