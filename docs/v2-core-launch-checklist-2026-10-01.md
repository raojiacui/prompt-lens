# V2 核心功能首发验收

日期：2026-10-01。目标分支：`prompt-lens-V2`。

## 首发范围

- 视频分析：手动上传、自动拆镜、逐镜头分析、提示词编辑与 AI 改写、发送到生成。
- 视频生成：生成任务、进度恢复、结果播放与下载。平台付费适配器目前仅 Wan 2.6 文生/单图生、720p、5 秒或 10 秒；不把其他 BYOK 模型的存在视为平台付费已验收。
- 登录、余额、订单、任务记录与管理员异常处理是核心功能的配套能力，不能隐藏。
- 音频分析和视频剪辑延后。发布前还需收敛首页宣传、工作台卡片、侧栏及旧直达链接，并关闭未发布的音频/剪辑提交接口；不要删除项目数据里的对白、声音或转场分析字段。
- 脚本改写属于视频分析到生成的核心链路，不因延后音频/剪辑而撤掉。
- TikTok 下载链路尚未通过正式运行环境验收；抖音/B站已有媒体链路记录，但也不等于用户端到端验收。链接导入不能成为手动上传首发的阻塞依赖。

## 本地配置差异

本地文件不等于 Vercel Production 配置。本次没有读取到可用的 Vercel 项目配置，因此所有线上配置状态仍需单独核验。

- 主目录 `.env.local`：开发桶 `promptlensdev`、支付宝沙箱；这两项应保留用于本地测试，不要为上线直接改成生产桶与真实扣款。
- EasyDown Key 仅在旧本地工作目录的私有配置里，主目录未配置；合并分支不会合并私有环境文件。后续需安全补齐主目录，不在文档或聊天传递 Key。
- 主目录 `COMMERCIAL_MIGRATION_ACCEPTED=0015`，代码要求 `0019`。核对目标结构与权限后才能更新验收标记。
- 主目录消费、改写、销售、调度验收关闭，付款/模型验收标记未设置；这是未开放状态，不应为了消除报错直接全开。
- 主目录未配置 GitHub OAuth 完整凭据；若首发保留 GitHub 登录，需配置并验收，否则隐藏该登录方式。邮箱验证码及保留的 Google 登录需真实验收。

## 生产配置核验

| 项目 | 核验标准 |
| --- | --- |
| 发布分支 | Vercel 生产部署来源确认为 `prompt-lens-V2`；GitHub 默认分支和 Vercel 生产分支分别确认，不依赖默认分支自动切换。 |
| 站点与登录 | `NEXT_PUBLIC_SITE_URL`、`NEXT_PUBLIC_BETTER_AUTH_URL` 使用正式 HTTPS 域名；OAuth 回调与邮件登录回跳可用。 |
| 邮件 | Resend SMTP、发件域名、验证码送达与限流，邮件图片公网可读；欢迎邮件可延后，不阻塞登录。 |
| 数据库 | 明确目标实例，核对结构、索引、权限、连接上限与迁移记录；保留原有钱包/订单，不重置数据。 |
| 存储 | Web 和 Worker 的生产桶均为 `prl`；权限、公开域名、浏览器直传 CORS、完成回执、跨用户归属校验正确。 |
| 清理 | 复查周期清理实际规则和前缀；验证不会误删官网素材或仍承诺保留的用户成果。明确用户素材保存期限。 |
| 模型 | KIE 平台 Key、实际使用的 API base、余额、请求/查询接口正确；BYOK 加密密钥稳定且不会被上线换掉。 |
| 链接 | 如开放，Production 配置 `EASYDOWN_API_KEY`；从实际 Worker 区域测下载与入库，失败不扣用户积分，核对服务商实际余额。 |
| Worker | 部署包含下载请求头和商业媒体接口的新版 Worker；相同共享密钥、生产 R2 配置、资源限制。Web 中最长 300 秒接口在部署配置下可运行。 |
| 后台调度 | Web/Worker 同一 `CRON_SECRET`；Worker 的 `COMMERCIAL_RECONCILIATION_BASE_URL` 为正式站点，关闭浏览器仍能推进任务与补单。只启用一套调度器。 |
| 支付 | 正式应用私钥、支付宝公钥、APP/商户 ID，生产网关与 `ALIPAY_SANDBOX=false`；公网异步通知 `/api/payments/webhooks/alipay` 可达且验签匹配。 |
| 额度 | 用户此前报告单笔 50 元、单日 1000 元。先确认当前额度；若未提额，59/129 元套餐需前后端一起暂停，不能拆单规避限制。 |
| 销售开关 | 迁移和调度验收通过后受控账号测试，真实付款/退款、模型账单验收后才填写版本标记 `2026-09-14-v6` 并开售；关闭受控验收模式。 |
| 用户承诺 | 核对首发功能、模型限制、失败退款/积分规则、素材保留期、客服渠道及隐私条款；生成记录目前保存供应商 URL，需测链接有效期和下载，不能未经验证承诺永久保存。 |

生产变量更新后需创建新的部署才能生效，详见 [Vercel 环境变量文档](https://vercel.com/docs/environment-variables)。函数时长以实际项目配置为准，详见 [函数时长配置](https://vercel.com/docs/functions/configuring-functions/duration)。

## 实视频验收矩阵

先用开发桶与授权测试账号；首轮少量模型调用，记录账单，避免批量消耗。

| 样本或操作 | 检查结果 |
| --- | --- |
| 5-10 秒单镜头 | 手动上传、免费试用/付费/BYOK 来源、提示词、重试、余额正确。 |
| 30 秒与 60 秒多镜头 | 上传回执、实际时长、自动拆镜、逐镜头预览、分析结果、累计费用与剩余积分一致。 |
| 横屏与竖屏、人像与产品 | 构图/人物/动作/运镜信息可用；提示词和参考图正确传到生成，不承诺像素级 1:1 还原。 |
| 暗场、快速转场、静态长镜头 | 拆镜漏检/过拆记录；不得超过 20 镜头限制后仍扣费执行。 |
| 超过 60 秒/100 MB、损坏/错误类型文件 | 服务端拒绝且不扣模型费用/用户积分；错误能理解，可重新选择文件。 |
| 镜头编辑与 AI 改写 | 新版本可恢复、中英文正确、成功只扣 1 次改写额度，失败释放。 |
| Wan 文生/单图生，5 秒/10 秒 | 每种配置至少一次授权真实调用，实际时长/分辨率/画面/有无音频、费用、供应商账单匹配。 |
| 余额不足、多条生成、重复点击 | 不足不启动；预留不重复；每条独立成功/失败结算。 |
| 关闭页面、断网、重登 | 任务继续推进，历史记录找回；未知任务不再次推理，待复核状态可处理。 |
| 结果播放与下载 | 桌面/手机正常播放，文件有声轨时可听，下载文件可播放；隔日检查供应商链接仍可用。 |
| 抖音/B站/TikTok | 逐平台检查解析、Worker 下载、R2 入库、后续分析与账单；下载未通过的平台不能宣传可用。 |
| 两个账号交叉访问 | 他人项目/素材/任务/订单不可读取或修改；普通账号不可访问管理员复核。 |
| 真实支付宝验收 | 用户授权并亲自付款，到账一次；另用未使用订单退款；重复通知/漏回调由查询恢复，不凭浏览器回跳入账。 |
| 目标 PostgreSQL 并发 | 重复确认、回调、退款竞争无负余额、无重复权益，账单能复算；PGlite 单连接测试不能替代。 |

每个样本记录：平台/时长/体积/镜头数、分析模型和费用来源、处理时长、分析结果、生成参数、积分预留与实扣、模型账单、错误与恢复情况。不要记录密钥、临时签名 URL 或用户私密素材。
