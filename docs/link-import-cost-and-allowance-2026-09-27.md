# 视频链接导入：成本与使用额度

> 历史方案：2026-10-01 已改为套餐 ¥21.90 / ¥63.90 / ¥139，含 12 / 30 / 61 次成功的视频链接导入，不额外扣积分，失败不计次。新规则见 package-price-update-2026-10-01.md；以下保留为旧方案记录，不再作为当前售价或扣费依据。

状态：本地实现及测试完成，未部署。只适用于抖音、TikTok、Bilibili 的公开视频单帖链接；TikTok 的完整下载链路仍需在正式运行环境验证。

## 对用户的规则

- 三档一次性套餐价格和通用积分保持不变：¥19.90 / 200 积分、¥59 / 650 积分、¥129 / 1500 积分。链接导入不赠送独立免费次数，也不消耗 AI 脚本改写次数。
- 成功导入一个视频并存入 R2 扣 10 通用积分。解析或转存明确失败，不扣积分。拆镜、分析、生成按各自既有规则另外报价。点击导入按钮前展示 10 积分费用。
- 如果只把积分用于链接导入，三档分别最多导入 20、65、150 次。这只是理论上限，不是叠加在积分之外的额外权益；实际同时使用其他功能时会相应减少。
- 余额不足时不调用付费解析服务；同一请求重试不会重复调用或扣积分。服务器无法判定最终结果时保留预留额度供人工核对，不自动再次向解析服务提交。

## 内部成本预算

以 [EasyDown 一次性 Starter 价格](https://easydown.org/pricing) $9 / 500 服务积分为基准。该页面标明抖音、TikTok、Bilibili 属于通常每次成功解析扣 1 服务积分的平台；内容受限但已产生确认处理成本时也可能扣费。服务积分与 Prompt Lens 通用积分是两种不同的单位。

| 项目 | 单次估算 |
| --- | ---: |
| EasyDown 解析裸成本 | $0.018 |
| 按预算汇率 ¥7.50 / $ | ¥0.135 |
| 加 20% 波动缓冲 | ¥0.162 |
| 10 个 Prompt Lens 积分的非改写履约预算（¥0.035 / 积分） | ¥0.350 |
| 留给 Worker 下载、R2 存储/流量、失败损耗的预算差额 | ¥0.188 |

上表 ¥0.188 不是已验证的实际利润。TikTok 下载路径尚未通过完整验证，R2 长期占用和 Worker P95 成本也未实测。只有解析成功且存储成功才向用户收费；解析服务可能对受限内容收取服务积分，所以失败损耗由上述预算承担。更高量的一次性套餐会降低服务积分采购单价，但首发预算不依赖批量折扣。$9 是运营预充值门槛，不是每个用户套餐的单独固定成本。

若全包积分仅用于链接导入，按缓冲后的服务成本，三档最大解析预算约 ¥3.24 / ¥10.53 / ¥24.30；它们分别包含在原套餐 ¥7.00 / ¥22.75 / ¥52.50 非改写履约预算内，不应再叠加扣一次。余下预算还需覆盖 Worker 和存储。原套餐贡献测算并不因此保证盈利，必须以真实账单复核。
